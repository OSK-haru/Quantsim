# 時間発展の検証

RK4・明示的CPTP・状態ベクトルの各時間発展経路が、解析解および独立ソルバーと一致することを検証します。各項目を「数式 → 説明 → 検査方法 → 検査結果」の順に記述します。

---

## 1. ゼロ散逸極限のユニタリ発展

### 数式

すべてのレートを 0 にすると、GKSL方程式の散逸項が消えて von Neumann 方程式になります。

$$
\frac{d\rho}{dt} = -i\left[H(t), \rho\right]
\quad\Longrightarrow\quad
\rho(\tau) = U\rho(0)U^\dagger
$$

Gate-awareモデルは列(column)のユニタリ $U_{\text{col}}$ と所要時間 $\tau$ から有効ハミルトニアン $H = \frac{\pi}{2\tau}(I - U_{\text{col}})$ を作って積分するため、散逸ゼロなら結果は $U_{\text{col}}\rho U_{\text{col}}^\dagger$ に厳密に一致するはずです。

### 説明

この検査は、**有効ハミルトニアンの逆算と積分器を経由した結果**が、**行列積で直接作ったユニタリ発展**と一致するかを問うものです。

一致しなければ、有効ハミルトニアンの構成、基底の順序、テンソル積の並び、多量子ビットゲートの埋め込みのいずれかに誤りがあります。ゼロ散逸極限は解析解が自明に得られるため、実装誤りが偶然一致する余地がほとんどありません。

### 検査方法

比較の対応は次のとおりです。

| 項目 | Yuragi-Strider側 | 参照側 | 対応 |
|---|---|---|---|
| 初期状態 | $\lvert0\cdots0\rangle$ の密度行列 | 同一の行列 | 同じオブジェクトを使用 |
| 発展 | 有効ハミルトニアン + 積分器 | $U_{\text{col}}\rho U_{\text{col}}^\dagger$ の直接計算 | 参照側は積分器を経由しない |
| 散逸 | `ideal_reference = true`(3レートすべて 0、崩壊演算子リスト空) | なし | 両者ともユニタリ |
| 出力時刻 | 各列の境界 | 同じ境界 | 同一時刻で比較 |

固定条件:

```text
待機時間 0、時間ステップ 101
ゲート所要時間: H / X / Z = 0.20 μs、CNOT = 0.40 μs
基底順: q0 が最上位ビット(|00>, |01>, |10>, |11>)
```

**検査ケース**(全8種)

| 1 | X | 1 | 1 | 最小構成での基本動作 |
| 2 | H | 1 | 1 | 重ね合わせの生成 |
| 3 | H → Z | 1 | 2 | 位相に対する感度 |
| 4 | Bell(H → CNOT) | 2 | 2 | 2量子ビットのもつれ |
| 5 | GHZ | 3 | 3 | 3量子ビットへの拡張 |
| 6 | 混成回路 | 4 | 3 | 基底順序とテンソル積の並び |
| 7 | 同一列に H と X | 2 | 1 | 同列に並ぶゲートの積 |
| 8 | 同一列に CNOT 2個 | 4 | 1 | 同列の2量子ビットゲート |

**許容誤差**

| 検査する量 | 許容誤差 |
|---|---|
| 最大要素誤差 $E_{\max}$ | $10^{-8}$ |

## 2. 励起状態の指数減衰

### 数式

$\lvert1\rangle$ から出発し、$H = 0$、$\gamma_\uparrow = \gamma_\phi = 0$ とすると、励起状態の占有確率は単純な指数減衰になります。

$$
P_1(t) = e^{-\gamma_\downarrow t}
$$

### 説明

崩壊演算子 $L_\downarrow = \sqrt{\gamma_\downarrow}\,\sigma^-$ の**係数の平方根規約**を確かめる検査です。係数を $\gamma_\downarrow$ と書き間違えれば減衰は $e^{-\gamma_\downarrow^2 t}$ になり、$1/2$ を落とせば時定数が2倍ずれます。指数の肩に現れる量を直接比較するため、これらは即座に検出されます。

### 検査方法

| 項目 | Yuragi-Strider側 | 参照側 | 対応 |
|---|---|---|---|
| 初期状態 | $\lvert1\rangle$ | 同一 | — |
| ハミルトニアン | 0 | 0 | 純粋な散逸過程 |
| レート | $\gamma_\downarrow$ のみ有限 | 同じ $\gamma_\downarrow$ を解析式に代入 | 上向き遷移と位相緩和は 0 |
| 比較量 | 各時刻の $P_1$ | $e^{-\gamma_\downarrow t}$ | 同一時刻の値どうし |

$\gamma_\downarrow = 0.010 / 0.050 / 0.100\ \mu\mathrm{s}^{-1}$ の3条件で実行します。

| 検査する量 | 許容誤差 |
|---|---|
| $P_1$ の最大絶対誤差 | $10^{-6}$ |
| $P_1$ の二乗平均平方根誤差 | $10^{-7}$ |

あわせて内部ステップを 0.5 → 0.25 μs に細分化して結果が変わらないことを確認します。

再現方法:

```powershell
.\.venv\Scripts\python.exe scripts\validate_excited_state_exponential_decay.py
```

### 検査結果

| $\gamma_\downarrow$ | 最大誤差 | フィット相対誤差 |
|---|---|---|
| 0.010 | 1.923961e-12 | 5.230191e-12 |
| 0.050 | 1.222742e-09 | 3.323757e-09 |
| 0.100 | 1.997610e-08 | 5.430066e-08 |

内部ステップ細分化(0.5 → 0.25 μs)の差は 1.804279e-12。

**判定: PASS**

レートが大きいほど誤差が増えるのは、固定ステップRK4の打ち切り誤差が減衰の速さに比例して増えるためで、想定どおりの振る舞いです。最大でも許容値の 1/50 に収まっています。

## 3. 純位相緩和

### 数式

$\lvert+\rangle$ から出発し、$\gamma_\phi$ のみを有限にすると、非対角要素だけが減衰します。

$$
\rho_{01}(t) = \rho_{01}(0)\,e^{-\gamma_\phi t},
\qquad
L_\phi = \sqrt{\frac{\gamma_\phi}{2}}\,\sigma_z
$$

崩壊演算子の係数に $1/2$ が入るのは、$\sigma_z$ による位相緩和がコヒーレンスを $2\times(\gamma_\phi/2) = \gamma_\phi$ の速さで減衰させるためです。

### 説明

この検査の主眼は、係数規約 $\sqrt{\gamma_\phi/2}$ が $\sqrt{\gamma_\phi}$ と取り違えられていないことの**積極的な判別**にあります。

単に「解析解と合う」ことを示すだけでなく、**誤った規約を仮定した曲線とは合わない**ことも同時に確認します。両者の差が測定誤差より十分大きければ、規約の取り違えは検出可能だと言えます。

### 検査方法

| 項目 | Yuragi-Strider側 | 参照側 | 対応 |
|---|---|---|---|
| 初期状態 | $\lvert+\rangle$ | 同一 | コヒーレンスが最大 |
| レート | $\gamma_\phi$ のみ有限 | 同じ $\gamma_\phi$ を解析式に代入 | 緩和・熱励起は 0 |
| 比較量 | $\rho_{01}(t)$ | $\rho_{01}(0)e^{-\gamma_\phi t}$ | 正しい規約 |
| 判別用の対照 | 同じ軌跡 | $\rho_{01}(0)e^{-2\gamma_\phi t}$ | 誤った規約($\sqrt{\gamma_\phi}\sigma_z$)を仮定した曲線 |

$\gamma_\phi = 0.010 / 0.050 / 0.100\ \mu\mathrm{s}^{-1}$ の3条件で実行します。

再現方法:

```powershell
.\.venv\Scripts\python.exe scripts\validate_pure_dephasing.py
```

### 検査結果

| $\gamma_\phi$ | 正しい規約との最大誤差 |
|---|---|
| 0.010 | 9.620638e-13 |
| 0.050 | 6.113710e-10 |
| 0.100 | 9.988049e-09 |

判別診断:

| 比較相手 | 最大誤差 |
|---|---|
| 正しい規約 $\sqrt{\gamma_\phi/2}\,\sigma_z$ | 1e-9 オーダー |
| 誤った規約 $\sqrt{\gamma_\phi}\,\sigma_z$ | 0.11932561(最小の非ゼロ時刻でも 3.346274e-03) |

**判定: PASS**

正しい規約との誤差と誤った規約との誤差は8桁以上離れており、規約の取り違えは確実に検出できます。

## 4. 時間ステップの収束

### 数式

固定ステップRK4の局所打ち切り誤差は $O(h^5)$、大域誤差は $O(h^4)$ です。したがってステップ幅 $h$ を半分にすると誤差はおよそ $1/16$ になり、観測次数は次式で 4 に近づくはずです。

$$
p = \log_2\frac{E(h)}{E(h/2)}
$$

### 説明

解析解と一致することと、数値解法が正しい次数で収束することは別の主張です。前者は特定の条件で偶然合っている可能性を排除できませんが、後者は**誤差がステップ幅に対して理論どおりに振る舞う**ことを示すため、積分器そのものの健全性を裏づけます。

同時に、出力時刻の刻み(スナップショット格子)を変えても結果が変わらないこと、Python実装とRust実装が一致することも確認します。

### 検査方法

内部最大ステップを **1.0 / 0.5 / 0.25 / 0.125 / 0.0625 μs** と細かくし、誤差の減り方を見ます。

| ケース | 参照 | 内容 |
|---|---|---|
| 1 | 解析解 | 下向き緩和 |
| 2 | 解析解 | 純位相緩和 |
| 3 | 解析解 | 有限温度緩和 |
| 4 | 0.03125 μs の細解 | 1量子ビットゲート(所要 8.0 μs) |
| 5 | 0.03125 μs の細解 | 2列回路(所要 8.0 μs + 16.0 μs) |

ケース4・5は解析解を持たないため、十分細かいステップで求めた数値解を参照とします。

**許容誤差**

| 検査する量 | 許容誤差 |
|---|---|
| 解析解ケース(1〜3)の最細ステップでの最大誤差 | $10^{-8}$ |
| ゲートケース(4・5)のステップ 0.125 μs での最大誤差 | $10^{-7}$ |
| ゲートケース(4・5)のステップ 0.0625 μs での最大誤差 | $10^{-8}$ |
| トレース誤差・Hermite性・最小固有値 | $10^{-10}$ |
| Python実装とRust実装の差 | $10^{-10}$ |

再現方法:

```powershell
.\.venv\Scripts\python.exe scripts\validate_time_step_convergence.py
```

アーティファクト: `validation_results/validation6_time_step_convergence.json`

|---|---|

補足:

:::

## 5. Gate-awareモデルとQuTiPの比較

### 数式

両者が解く方程式は同一のGKSL方程式です。

$$
\frac{d\rho}{dt}
= -i\left[H_k, \rho\right]
+ \sum_k \left(L_k \rho L_k^\dagger - \frac{1}{2}\left\{L_k^\dagger L_k, \rho\right\}\right)
$$

異なるのは解き方だけです。Yuragi-Striderは固定ステップRK4、QuTiPは適応刻みのDOP853で積分します。比較する誤差は共通指標 $E_{\max}$ とトレース距離 $D$ です。

### 説明

解析解が存在しない条件(ゲート由来の有効ハミルトニアン、2量子ビット回路)での正しさを、**独立に実装された積分器**との一致で確かめます。

この比較で検出できるのは積分器・ステップ制御・区間の接続に関する誤りです。行列そのものはYuragi-Striderが構成したものをQuTiPへ渡すため、行列構成の誤りは検出できません(行列構成の独立検証は[制御モデルの検証](./control-models.md)の結合ネットワークの項で扱います)。

### 検査方法

**入力の対応**

| 項目 | Yuragi-Strider側 | QuTiP側 | 対応 |
|---|---|---|---|
| 初期状態 $\rho(0)$ | 内部で構成した密度行列 | 同じ行列を `Qobj` に変換して投入 | 完全に同一のオブジェクト |
| ハミルトニアン | ゲート列から逆算した有効ハミルトニアン $H_k$ | 同じ行列を `Qobj` に変換して投入 | QuTiPのスピン演算子で組み直さない |
| 崩壊演算子 | $\sqrt{\gamma_\downarrow}\sigma^-$ 等を多量子ビットへ埋め込んだ行列 | 同じ行列群を `c_ops` として投入 | 個数・順序とも同一 |
| 区間長 | 各ゲート列の所要時間 | 同じ区間長で逐次実行し、境界で状態を引き継ぐ | 区間境界が一致 |
| 出力時刻 | 待機系は 0 / 2.5 / 5 / 10 / 20 / 50 μs、回路系は各列の境界 | 同じ時刻列を `tlist` に指定 | 同一時刻で突き合わせ |
| 積分方法 | 固定ステップRK4(内部最大 0.03125 μs) | `mesolve` / DOP853(`atol = rtol = 1e-12`、`nsteps = 100000`、最大ステップ 0.015625 μs、`normalize_output = false`) | **意図的に異なる**(ここが独立性の源) |
| 基底順 | q0 を最上位ビットとする $\lvert00\rangle,\lvert01\rangle,\lvert10\rangle,\lvert11\rangle$ | `dims` で同じ部分系次元を指定し、並べ替えを行わない | 同一 |

**ケースと入力値**

|---|---|---|---|---|
| 1 | 下向き緩和 | $\lvert1\rangle$ | $\gamma_\downarrow = 0.1$ | 0 |
| 2 | 純位相緩和 | $\lvert+\rangle$ | $\gamma_\phi = 0.1$ | 0 |
| 3 | 有限温度緩和 | $\lvert1\rangle$ | $\gamma_\downarrow = 0.051$、$\gamma_\uparrow = 0.049$ | 0 |

## 6. 明示的CPTPとRK4の突き合わせ

### 数式

明示的CPTP経路は、区間内でGKSL生成子を定数とみなし、Liouvillian $\mathcal{L}$ の行列指数として写像を作ります。

$$
\operatorname{vec}\big(\rho(t+\Delta t)\big) = \exp\left(\mathcal{L}\,\Delta t\right)\operatorname{vec}\big(\rho(t)\big)
$$

この写像は構成上CPTPであり、Choi行列 $J(\mathcal{E})$ の最小固有値と部分トレースで検査できます。

$$
\lambda_{\min}\big(J(\mathcal{E})\big) \ge -\epsilon,
\qquad
\left\|\operatorname{Tr}_{\text{out}} J(\mathcal{E}) - I\right\|_F \le \epsilon
$$

一方RK4は $\rho$ を直接積分するため、有限ステップでの写像がCPTPである保証はありません。

### 説明

同じ物理を2つの経路で解き、ステップを細かくするほど両者が近づくことを確認します。これは**どちらか一方が誤っていない**ことの相互確認になります。

同時に、RK4が破綻する領域では明示的CPTPが物理的な状態を保ち続けることも観察します。この対比は、密度行列の整形(cleanup)が発散したRK4を救済しないという設計上の主張を数値的に裏づけます。

## 7. 明示的CPTPとQuTiPの比較

### 数式

明示的CPTP経路は時間依存のパルスに対して、区間の中点における生成子で区分定数近似します。

$$
\rho(t_{k+1}) = \exp\left(\mathcal{L}\!\left(t_k + \tfrac{\Delta t}{2}\right)\Delta t\right)\rho(t_k)
$$

したがって区間幅 $\Delta t$ を小さくすれば、連続的な時間依存問題の厳密解へ収束するはずです。QuTiPの適応刻み解を参照として、区間境界でのトレース距離が単調に減少することを確かめます。

### 説明

前項がRK4との内部比較だったのに対し、この項は**外部の独立ソルバーとの比較**です。

比較の条件を実行前に確定させる方式(事前登録)を採っています。結果を見てから許容誤差を決めれば、どんな結果でも「合格」にできてしまうためです。

### 検査方法

**入力の対応**

| 項目 | Yuragi-Strider側 | QuTiP側 | 対応 |
|---|---|---|---|
| 初期状態 | 内部で構成した密度行列 | 同じ行列を投入 | 同一 |
| ハミルトニアン | 各区間の中点で評価した $H(t)$ 行列 | 同じ時間依存ハミルトニアンを連続的に評価 | **意図的に異なる**(区分定数 vs 連続) |
| 崩壊演算子 | 内部で構成した行列群 | 同じ行列群を `c_ops` に投入 | 同一 |
| 比較時刻 | すべての区間境界 | 同じ境界時刻を `tlist` に指定 | 全境界で突き合わせ |
| 積分方法 | 中点区分定数GKSL指数の合成 | `mesolve` / DOP853、最大ステップは **CPTP区間幅 / 8** | 参照側を十分細かく取る |
| バックエンド | Python と Rust の両方 | 共通 | 両バックエンドが同じ結果を返すことも確認 |

**事前登録した合格条件**

| 条件 | 値 |
|---|---|
| トレース誤差・Hermite性・最小固有値の許容 | $10^{-10}$ |
| Python実装とRust実装の一致許容 | $2\times10^{-10}$ |
| 収束の単調性に許す揺らぎ | $10^{-12}$ |
| 必須のバックエンド | Python と Rust の両方 |
| 区間サイズ | ケースごとに3種を実行前に確定 |
| 比較する時刻 | すべての区間境界 |
| QuTiP側の最大ステップ | 区間幅 / 8 |
| 最細ステップでのトレース距離の上限(2準位Gaussianパルス) | $5\times10^{-5}$ |
| 最細ステップでのトレース距離の上限(qutrit DRAGパルス) | $2\times10^{-4}$ |

**ケースの入力値**

|---|---|---|---|

## 8. 明示的CPTPモデルの契約凍結

### 数式

凍結の対象は、実装が従う規約そのものです。Choi行列の規約は非正規化・入力⊗出力の行優先で、次を満たします。

$$
\operatorname{Tr} J(\mathcal{E}) = d,
\qquad
J(\mathcal{E}) = \sum_{jk} \lvert j\rangle\langle k\rvert \otimes \mathcal{E}\big(\lvert j\rangle\langle k\rvert\big)
$$

### 説明

数値が一致することと、その数値を生む**規約が固定されていること**は別です。ベクトル化の順序や行列指数の実装が後から変われば、同じ入力でも異なる結果になりえます。

この項目は、検証時点の規約と実装ファイルの内容をハッシュとともに記録し、以後の変更を検出可能にするものです。

### 検査方法

凍結される規約:

```text
Choi規約   : 非正規化・入力 ⊗ 出力・行優先(Tr(J) = d)
CP / TP許容 : 1e-12 / 1e-12
ベクトル化 : 列優先
行列指数   : scaling and squaring 法(Padé 13次)、Python版とRust版
時間依存性 : 中点区分定数
単位       : μs / rad·μs⁻¹ / sqrt(1/μs) / 1/μs
整形       : 適用しない
```

29個のソースファイルのハッシュを含むマニフェストを生成し、記録します。

```powershell
.\.venv\Scripts\python.exe scripts\freeze_cptp_model.py
```

アーティファクト: `validation_results/cptp_model_freeze.json`

### 検査結果

**判定: PASS WITH RESTRICTIONS**

凍結時点で明示された制限は次のとおりです。

- 校正済みハードウェア予測を確立しない
- 非マルコフ的ダイナミクスを扱わない
- 実験室系の搬送波積分を行わない
- 多量子ビットパルス制御を確立しない

このうち「CPTPとQuTiPの突き合わせが未完了」という制限は、上記「7. 明示的CPTPとQuTiPの比較」により解消済みです。

## 9. 数値健全性チェック

### 数式

すべてのシミュレーション結果に対する最低限の検査です。

$$
\left|\operatorname{Tr}\rho - 1\right| \le \epsilon,
\qquad
\left\|\rho - \rho^\dagger\right\|_{\max} \le \epsilon,
\qquad
\lambda_{\min}(\rho) \ge -\epsilon,
\qquad
\sum_i p_i = 1
$$

### 説明

上記1〜8が特定の条件に対する精密な検証であるのに対し、この検査はすべての実行に対する**明白な破綻の検出**を目的とします。精度の保証ではなく、異常の早期発見のための網です。

### 検査方法

各シミュレーション結果について次を確認します。

- NaN / inf が存在しないこと
- Fidelity と Purity が $[0,1]$ に収まること
- 出力確率の和が 1 になること
- トレースが 1 に近いこと
- Hermite性の破れが小さいこと
- 最小固有値が大きく負に振れないこと

### 検査結果

**判定: 全実行で通過**

:::note
この検査は「**研究グレードのシミュレーション精度を保証するものではありません**」。あくまで明白な破綻の検出用です。精度の根拠は1〜7の各項目にあります。
:::
