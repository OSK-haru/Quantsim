# 現在の制限事項

Yuragi-Striderは、小規模・弱結合Markov近似を前提とした教育用シミュレーターです。校正済みのハードウェアモデルではありません。

## 扱わないもの

- 強結合(系と環境の相互作用は弱結合を前提とします)
- 非Markov過程(環境の記憶効果)
- 実験室系での搬送波積分(Pulse-levelモデルはすべて回転波近似)
- クロストーク・伝達関数・可変結合器
- 実機校正に基づく予測
- モンテカルロ軌跡(未実装。APIは `trajectory_available: false` を返します)

唯一の例外として、Pulse-levelモデルの**準静的ノイズ**はショットごとに固定された離調のアンサンブル平均として扱われますが、これは厳密な非マルコフ性の記述ではありません。

## 準位数と漏れ(leakage)について

扱える準位数は制御モデルによって異なります。

| モデル | 準位数 | 漏れの扱い |
|---|---|---|
| Gate-aware | 2(量子ビットあたり) | 表現しない |
| Pulse Baseline A | 2 | 表現しない |
| Pulse Extension B | 3(qutrit) | **第3準位への漏れを表現する** |
| Coupled transmon network | $L^N$($L\in\{2,3\}$、$N\le4$) | 3準位なら**各トランズモンの第3準位への漏れを表現する**。2準位では表現しない |

Gate-awareモデルと2準位のPulse Baseline Aは漏れを扱いませんが、Pulse Extension Bと、3準位を選んだ結合ネットワークは漏れとそのDRAG補正を扱えます。ネットワークで2準位を選んだ場合は漏れが存在しません。

ただし3準位モデルであっても、漏れが大きい領域では切り詰めそのものが妥当でなくなります。検証では漏れが約94%に達するケースが記録されており、この領域はハードウェアの予測器として使用できません。

## 規模の上限

```text
最大論理量子ビット数           : 18
密度行列(ノイズあり)の上限     : 8
状態ベクトル経路の上限         : 18
古典分岐の上限                 : 4096
```

ノイズを含む計算は8量子ビットまでです。それを超える場合は、環境が理想的かつ測定を含まない回路に限り状態ベクトル経路で実行されます。

6〜8量子ビットのノイズありの回路では、時間発展方式はRK4に限られます(明示的CPTP経路は超演算子の次元が $4^n$ で増えるため選べません)。

### Pulse-levelネットワークの別上限

Gate-awareの「8量子ビット密度行列」と、Pulse-levelのトランズモン・ネットワークは別の上限です。ネットワークは **1〜4台**を受け付け、密度行列は $L^N$ 次元(最大 $3^4 = 81$)になります。

| トランズモン数 $N$ | Hilbert次元 $3^N$ | 密度行列要素数 $3^{2N}$ |
|---:|---:|---:|
| 2 | 9 | 81 |
| 3 | 27 | 729 |
| 4 | 81 | 6,561 |

実行可否は台数だけではなく、`estimated_steps × ((3^N)^3 + 12,000) ≤ 1,200,000,000` と、全スナップショットを合わせた行列要素数250,000以下で判定します。4台では内部ステップ約2,200回、スナップショット38点までが上限で、これは16 nsのGaussianパルスを各レーンに1〜2個並べる規模にあたります。ネットワークでは明示的CPTP、準静的ノイズ、5台以上を扱いません。

Pulse Labの密度行列表示は、10次元以上では全体を既定表示しません。行・列を基底ラベルまたは `#要素番号` で検索し、選択セルの周囲±1〜±3を表示します。27次元以下は必要に応じて全体表示へ切り替えられます。
