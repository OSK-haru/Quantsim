# Yuragi-Striderとは

Yuragi-Striderは、超伝導型量子コンピューターを想定した量子回路を開放量子系として扱い、
ゲート実行中の環境ノイズと量子状態の変化を可視化する
教育・体験用シミュレーターです。

## 特徴

従来の量子回路シミュレーターは理想的なものが多く、現実の環境が生むノイズや誤差を無視しています。

専用のライブラリを使えば開放量子系のシミュレート自体は可能ですが、そこには次の問題がありました。

- 入力をハミルトニアンや崩壊演算子の形で与える必要があり、実際の温度や磁束ノイズとの対応付けが難しい
- GUIを持たず、コードを書かなければ試せない
- 状態がどう崩れていくかを直観的に確かめる手段が乏しい

Yuragi-Striderは、この3点をまとめて扱います。GUI上で量子回路を組み、温度や磁束ノイズといった**物理量そのものの単位**で環境を指定すると、開放量子系としての時間発展が計算され、密度行列・Fidelity・Purity・出力確率などの形で結果が返ります。
