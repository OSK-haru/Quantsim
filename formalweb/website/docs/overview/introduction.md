# Q-Striderとは

Q-Striderは、超電導型量子コンピューターを想定した量子回路を開放量子系として扱い、
ゲート実行中の環境ノイズと量子状態の変化を可視化する
教育・体験用シミュレーターです。

### 特徴

従来の量子回路シュミレーターは理想的なものが多く、
現実世界における環境によるノイズや誤差を無視している場合
仮に専用のライブラリ等でシュミレート出来ても直観的な操作は難しく、入力もハミルトニアン等で指定する必要があり、実際の温度や磁束との対応付けが難しかったり、GUI操作に対応していないなどの問題点があったが、は、GUI、量子開放系、量子回路シュミレート、より直感的な単位入力を実現している。
