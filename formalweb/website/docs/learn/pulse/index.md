# パルス編 — 履修ガイド

[第6章](../pulse-control.md)では、駆動された量子ビットの物理をひととおり見ました。このパルス編は、そこから先を**独立した課程として履修する**ための7章です。

Gate-awareモデルが「ゲートは所要時間を持つ行列」という抽象で止まるのに対し、Pulse-levelモデルは**実機の制御そのもの**を扱います。ここを理解すると、次の問いに答えられるようになります。

- なぜトランズモンは非調和なのか。非調和性 $\alpha$ はどこから来る数か
- なぜ速いゲートほど漏れるのか。それを式で見積もれるか
- DRAGはなぜ効くのか。$\beta$ の最適値はどう決まるか
- 3準位の位相緩和で $\rho_{01}:\rho_{12}:\rho_{02} = 1:1:4$ になるのはなぜか
- $1/f$ ノイズはなぜGKSL方程式で書けないのか。ではどう扱うのか
- 2つのトランズモンを繋ぐと、なぜ2量子ビットゲートができるのか

## 前提

**必須**: 本編[第1章](../quantum-state.md)〜[第3章](../open-systems.md)、および[第6章](../pulse-control.md)

第6章の内容(回転系、RWA、Rabi振動、パルス面積定理、Duffing形のハミルトニアン)は前提として使います。読んでいない場合は先に通してください。

**あると望ましい**: [第4章](../decoherence.md)(散逸レート)、[第7章](../numerical-integration.md)(RK4と収束)

## 3つのモデルとの対応

Yuragi-Striderのパルスモデルは3段階に積み上がっています。パルス編もこの順に難しくなります。

```text
Baseline A (2準位)
  └─ 駆動・回転系・RWA・包絡線     ← P2
       │
       ▼ 第3準位を足す
Extension B (qutrit)
  └─ 非調和性・漏れ・DRAG          ← P1, P3
  └─ 遷移別散逸・数演算子位相緩和   ← P4
  └─ 準静的ノイズ                  ← P5
       │
       ▼ 2つ繋ぐ
Coupled transmon pair (3⊗3)
  └─ 交換結合・2量子ビットゲート    ← P6
```

P7だけは全モデルに横断的にかかります。

:::info[実験扱いのモデルがあります]
Coupled transmon pair は状態 **experimental** です。API契約は凍結されていますが、他の2モデルより検証の範囲が狭く、非対称なペアを表現できないなどの制限があります。P6でその内容を扱います。
:::

## 読みかたの2コース

**最短コース(パルスで何が起きているかを掴む)**
P1 → P2 → P3

トランズモンとは何か、パルスをどう作るか、なぜ漏れるか。この3つで Pulse Lab の主要な操作が理解できます。

**完全履修コース**
P1 → P2 → P3 → P4 → P5 → P6 → P7

P7を最後に置いているのは、そこまでの物理を知らないと「なぜこのステップ幅が必要なのか」が理解できないためです。

## Pulse Labでの実習について

パルス編の演習には 🔬 付きのものが多く含まれます。Pulse-levelモデルは**単発パルスのフロー**なので、Circuit Studioで作った回路とは連携しません。Pulse Labで直接パラメータを与えて実行してください。

:::tip[実習の基本形]
1. 理論から予測を立てる(この条件なら漏れは何%くらいのはず)
2. Pulse Labで実行する
3. 一致しなければ、**理論と実装のどちらの前提が違うか**を切り分ける

3番目が最も学べる部分です。Yuragi-Striderは前提と制限をすべて公開しているので、切り分けが可能です。
:::

## このコースの限界

:::warning[実機の設計を学ぶコースではありません]
ここで扱うのは、Yuragi-Striderが実装しているモデルの物理です。実機のトランズモン設計、較正手順、読み出し回路、パルス伝達関数、クロストーク補正といった実務は扱いません。

特に次はモデルに存在しません。

- 実験室系での搬送波積分(RWAのみ)
- パルスの伝達関数・歪み(理想的な包絡線がそのまま量子ビットに届くと仮定)
- クロストーク、可変結合器、周波数チューニング
- 読み出しと測定誤差
- 較正済みのデバイスパラメータ

全体像は[前提と適用範囲](../../physics-model/assumuptions.md)を参照してください。
:::
