# P6. 結合トランズモン対

:::info[このページで学ぶこと]
- 交換結合 $J(a_0^\dagger a_1 + a_0 a_1^\dagger)$ が励起数を保存すること
- 9次元空間が励起数でブロックに分かれること
- 単一励起部分空間から iSWAP が出てくる導出
- $\lvert11\rangle$ と $\lvert02\rangle$ の避けられた交差、CZ の原理
- 常時オンの $ZZ$ 相互作用がなぜ生じるか、その大きさの見積もり
- ステップ制限 $h \le 0.02/(4J)$ の由来
- このモデルが **experimental** である理由

**前提**: [P1](./transmon.md)、[P4](./qutrit-dissipation.md)
:::

## P6.1 2量子ビットゲートの難しさ

1量子ビットゲートは、狙った量子ビットにマイクロ波を当てるだけで作れました。2量子ビットゲートはそうはいきません。

$$
\text{エンタングルメントを作るには、2つの量子ビットが\textbf{相互作用}している必要がある}
$$

しかし相互作用が常にあると、ゲートを掛けていない間も勝手に絡み合ってしまいます。**必要なときだけ効き、それ以外では効かない相互作用**をどう作るかが、超伝導量子計算のいちばん難しい設計課題です。

Yuragi-Striderが扱うのは、最も基本的な**交換結合**(exchange / hopping coupling)です。

$$
H_{\text{int}} = J\left(a_0^\dagger a_1 + a_0 a_1^\dagger\right)
$$

キャパシタで2つのトランズモンを繋ぐと、この形の項が現れます。

## P6.2 励起数の保存

$a_0^\dagger a_1$ は「量子ビット1から励起を1つ取り、量子ビット0へ渡す」操作です。$a_0 a_1^\dagger$ はその逆。どちらも**励起の総数を変えません**。

$$
\left[\,H_{\text{int}},\ \hat N\,\right] = 0,
\qquad
\hat N = \hat n_0 + \hat n_1
$$

これは強力な性質で、9次元の空間がブロック対角に分かれます。

| 励起数 $N$ | 状態 | 次元 |
|---|---|---|
| 0 | $\lvert00\rangle$ | 1 |
| 1 | $\lvert10\rangle,\ \lvert01\rangle$ | 2 |
| 2 | $\lvert20\rangle,\ \lvert11\rangle,\ \lvert02\rangle$ | 3 |
| 3 | $\lvert21\rangle,\ \lvert12\rangle$ | 2 |
| 4 | $\lvert22\rangle$ | 1 |

**$9\times9$ の問題が、$1+2+3+2+1$ の小さな問題に分解されます。** 以下ではこのブロックごとに何が起きるかを見ます。

:::note[駆動は励起数を保存しない]
$H_{\text{int}}$ は励起数を保存しますが、駆動項 $\frac{\Omega}{2}(a^\dagger + a)$ は保存しません。ブロック分解が使えるのは**駆動がない区間**の話です。

とはいえ、駆動があってもこの構造は解析の指針として有効です。以下の議論はすべて「駆動を止めた状態で結合を効かせる」場面に対応します。
:::

## P6.3 単一励起部分空間 — iSWAP

$N = 1$ のブロックは $\{|10\rangle, |01\rangle\}$ の2次元です。$a_0^\dagger a_1|01\rangle = |10\rangle$、$a_0a_1^\dagger|10\rangle = |01\rangle$(どちらも係数1)なので

$$
H_{N=1} = J\big(|10\rangle\langle01| + |01\rangle\langle10|\big) = J\,\sigma_x^{(N=1)}
$$

**この部分空間では、交換結合はただの $\sigma_x$ です。** 2準位の Rabi 振動とまったく同じ形になります。

$$
U(t) = e^{-iJt\sigma_x} = \cos(Jt)\,I - i\sin(Jt)\,\sigma_x
$$

$Jt = \pi/2$ のとき

$$
|10\rangle \ \longrightarrow\ -i\,|01\rangle,
\qquad
|01\rangle \ \longrightarrow\ -i\,|10\rangle
$$

$$
\boxed{\ t_{\text{iSWAP}} = \frac{\pi}{2J}\ }
$$

励起が完全に入れ替わり、$-i$ の位相が付きます。これが **iSWAP ゲート**です。$Jt = \pi/4$ で止めれば $\sqrt{\text{iSWAP}}$ で、こちらはそれ単体でエンタングルメントを作れます。

:::tip[結合強度が「速さ」を決める]
$J/2\pi = 5$ MHz なら $J = 31.4$ rad/μs で

$$
t_{\text{iSWAP}} = \frac{\pi}{2\times31.4} = 0.050\ \mu\mathrm{s} = 50\ \mathrm{ns}
$$

1量子ビットゲート(20 ns 程度)の2〜3倍。実機で2量子ビットゲートが遅く、誤差が大きい理由がここに見えます。**$J$ を大きくすれば速くなりますが、次節の $ZZ$ 誤差も増えます。**
:::

## P6.4 2励起ブロック — $\lvert11\rangle$ の運命

$N = 2$ のブロックは3次元 $\{|20\rangle, |11\rangle, |02\rangle\}$ です。ここが2量子ビットゲートの核心であり、同時に漏れの温床です。

$a_0^\dagger a_1$ を $|11\rangle$ に作用させると、はしごの $\sqrt2$ が出てきます([P4](./qutrit-dissipation.md))。

$$
a_0^\dagger a_1|11\rangle = \sqrt2\,|20\rangle,
\qquad
a_0 a_1^\dagger|11\rangle = \sqrt2\,|02\rangle
$$

$$
H_{N=2} = \sqrt2\,J\Big(|20\rangle\langle11| + |11\rangle\langle02| + \text{h.c.}\Big)
$$

**$|11\rangle$ は $\sqrt2 J$ という強い結合で、両側の漏れ準位に繋がっています。**

エネルギーを見ます。2つのトランズモンが同一($\omega_0=\omega_1=\omega$、$\alpha_0=\alpha_1=\alpha$)とすると

$$
E_{|11\rangle} = 2\omega,
\qquad
E_{|20\rangle} = E_{|02\rangle} = 2\omega + \alpha
$$

**離調はちょうど $\alpha$ です。** ここでも非調和性が、計算空間を漏れから守る唯一の壁になっています。

```text
        │11⟩ ────────────  2ω
                            ▲
                            │ 離調 |α|、結合 √2 J
                            ▼
  │20⟩, │02⟩ ────────────  2ω + α
```

### CZ ゲートの原理

$|11\rangle$ と $|02\rangle$ を**意図的に共鳴させる**と、この2準位のあいだで完全な振動が起きます。ちょうど1周($2\pi$ 回転)させて戻すと、$|11\rangle$ は位相 $-1$ を拾います。他の基底状態は動かないので

$$
\operatorname{diag}(1,1,1,-1) = \mathrm{CZ}
$$

が得られます。実機の CZ ゲートはこの原理で作られています。

:::warning[Yuragi-Striderでは周波数を動かせません]
実機の CZ は、磁束で量子ビット周波数を**時間的に変えて** $|11\rangle$ と $|02\rangle$ を共鳴点へ持っていきます。

Yuragi-Striderの結合ペアモデルは、離調を**区間ごとの定数**として受け取ります。時間依存の周波数チューニング(フラックスパルス)は入力にありません。

したがって、**教科書的な断熱 CZ ゲートはこのモデルでは組めません**。静的な離調を共鳴条件に設定して振動を観察することはできますが、それは CZ ゲートの実装ではなく、機構の観察です。
:::

## P6.5 $ZZ$ 相互作用 — 消えない誤差

$|11\rangle$ と $|20\rangle,|02\rangle$ が共鳴していなくても、**準位反発**は常に起きます。2次の摂動論で $|11\rangle$ のエネルギーがずれます。

$$
\delta E_{|11\rangle}
= \frac{\lvert\sqrt2 J\rvert^2}{E_{11}-E_{20}} + \frac{\lvert\sqrt2 J\rvert^2}{E_{11}-E_{02}}
= \frac{2J^2}{-\alpha} + \frac{2J^2}{-\alpha}
= \frac{4J^2}{\lvert\alpha\rvert}
$$

($\alpha<0$ なので $-\alpha = |\alpha| > 0$、つまり $|11\rangle$ は**押し上げられます**。)

この $\zeta \equiv \delta E_{|11\rangle}$ が **$ZZ$ 相互作用**です。なぜ問題かというと

$$
E_{11} - E_{10} - E_{01} + E_{00} = \zeta \ne 0
$$

つまり**片方の量子ビットの周波数が、もう片方の状態に依存する**ということです。何もしていない待機中にも、$|11\rangle$ だけが余分な位相を蓄積しつづけます。

$$
|11\rangle \ \longrightarrow\ e^{-i\zeta t}|11\rangle
$$

### 大きさの見積もり

$J/2\pi = 5$ MHz、$|\alpha|/2\pi = 250$ MHz とすると

$$
\zeta = \frac{4J^2}{\lvert\alpha\rvert}
= \frac{4\times(31.4)^2}{1571} = 2.5\ \mathrm{rad/\mu s}
\quad\Longleftrightarrow\quad
\frac{\zeta}{2\pi} \approx 0.4\ \mathrm{MHz}
$$

$1/\zeta \approx 0.4$ μs で $|11\rangle$ に $\pi$ 相当の位相が溜まります。ゲート時間 50 ns に対して無視できる大きさではありません。

:::tip[$J$ を上げると速くなるが、$ZZ$ は二乗で増える]
| 量 | $J$ への依存 |
|---|---|
| iSWAP 時間 | $\propto 1/J$ |
| $ZZ$ 相互作用 $\zeta$ | $\propto J^2$ |

$J$ を2倍にするとゲートは2倍速くなりますが、$ZZ$ は4倍になります。**この対立を解くために、実機は可変結合器(tunable coupler)で $J$ そのものをオン・オフできるように設計されています。**

Yuragi-Striderは可変結合器を持たないので、$J$ は常時オンです。この制限は、$ZZ$ の効果を素直に観察できるという意味では教材向きです。
:::

## P6.6 ステップ制限 $h \le 0.02/(4J)$ の由来

結合ペアモデルには、他のモデルにない追加のステップ制限が入ります。

$$
h \le \frac{0.02}{4J}
$$

この $4J$ という数がどこから来るかを追ってみます。

**第1段: ハミルトニアンのノルム**
2励起ブロックの $H_{N=2}$ は $\sqrt2 J(|20\rangle\langle11| + |11\rangle\langle02| + \mathrm{h.c.})$ で、固有値は $0, \pm2J$ です。3励起ブロック $\{|21\rangle,|12\rangle\}$ の結合も $2J$ になります。したがって

$$
\lVert H_{\text{int}}\rVert = 2J
$$

**第2段: Liouvillianのノルム**
[第8章](../quantum-channels.md)で見たとおり、時間発展の生成子は交換子 $-i[H,\cdot]$ です。ベクトル化すると $-i(I\otimes H - H^{\mathsf T}\otimes I)$ で、そのノルムは $H$ の**2倍**まで届きます。

$$
\lVert\mathcal{L}_{\text{int}}\rVert \le 2\lVert H_{\text{int}}\rVert = 4J
$$

**第3段: ステップ方針**
[第7章](../numerical-integration.md)の考え方どおり、$h\cdot\lVert\mathcal{L}\rVert \le \varepsilon$ を課します。qutrit系の $\varepsilon = 0.02$ を使って

$$
h \le \frac{0.02}{4J}
$$

**$4 = 2(\text{交換子}) \times 2(\text{はしご})$ です。** 実装の定数が、物理と数値の両方から一意に決まっていることが分かります。

$J/2\pi = 5$ MHz なら $h \le 1.6\times10^{-4}$ μs。パルス長 50 ns に対して 300 ステップ以上が必要になります。

## P6.7 実装の制限

:::warning[このモデルは experimental です]
| 制限 | 内容 |
|---|---|
| **単一のレートプロファイルを共有** | 両方のトランズモンが同じ $\gamma$ を持つ。非対称なペアは表現不可 |
| 厳密に $N=2$ | 3つ以上のトランズモンには拡張されない |
| 交換結合のみ | 容量性・誘導性の他の結合形は扱わない |
| 可変結合器なし | $J$ は定数。オン・オフできない |
| 周波数チューニングなし | 離調は区間ごとの定数。フラックスパルス不可 |
| クロストークなし | 一方への駆動が他方に漏れる効果はない |
| 較正なし | 実機のパラメータを再現するものではない |

最初の項目はAPIレスポンスの警告としてクライアントに通知されます。**「実行できたから妥当」ではないことを、実装自身が申告する設計**です。

作業量の上限も他より厳しく設定されています(15,000 RK4ステップ / 500 CPTP区間)。9次元の系を[P5](./quasi-static-noise.md)の求積点ごとに解くため、コストが急速に増えるためです。
:::

## 演習

1. $H_{N=1} = J\sigma_x$ から、$|10\rangle$ を初期状態としたときの $P(|01\rangle)$ の時間変化を求めよ。周期はいくらか。

2. $\sqrt{\text{iSWAP}}$($Jt = \pi/4$)を $|10\rangle$ に作用させた結果を書き下し、それがエンタングルした状態であることを確かめよ。

3. $H_{N=2}$ の $3\times3$ 行列を書き下し(離調 $\alpha$ を対角に含めて)、$\alpha = 0$ のときの固有値が $0,\pm2J$ になることを確かめよ。

4. 3励起ブロック $\{|21\rangle,|12\rangle\}$ について $a_0^\dagger a_1|12\rangle = 2|21\rangle$ を確かめよ($\sqrt2\times\sqrt2$)。

5. $\zeta = 4J^2/\lvert\alpha\rvert$ を使い、$\zeta$ を 0.1 MHz 以下に抑えるための $J$ の上限を $\lvert\alpha\rvert/2\pi = 250$ MHz について求めよ。そのときの iSWAP 時間はいくらか。

6. $\zeta$ を「常時オンの $ZZ$ 誤差」として、iSWAP ゲート1回($t = \pi/2J$)のあいだに $\lvert11\rangle$ が蓄積する位相を $J$ の関数として求めよ。この位相は $J$ に依存するか。

7. 🔬 **Pulse 回路スタジオ**でq0に短いSquare・回転角 $\pi$ のX Pulseを1つ置いて保存する。**Pulseラボ**で「量子系モデル」を「2トランズモン結合(9次元)」、「駆動対象」をq0とし、「観測時間 [us]」をPulse幅より十分長くする。環境入力を「Lindblad率を直接指定」にして各率を0にし、実行せよ。Pulse直後にP10が大きくなり、その後「占有確率と品質指標」でP10とP01が交換振動することを確認する。グラフの周期を「交換結合 J [rad/us]」から予測した周期と比較せよ。

8. 🔬 結合モデルのまま、q0の主Pulseと「同時セカンダリdrive」をともにSquare・回転角 $\pi$、同じ短いPulse幅に設定して、$|00\rangle$から$|11\rangle$付近を準備する。実行後、「占有確率と品質指標」の「リーケージ」と「最終密度行列」の $|20\rangle$、$|02\rangle$ 対角セルを確認せよ。q0の「非調和性 [MHz]」と「q1 非調和性 [MHz]」の絶対値を同時に変え、リーケージがどう動くか比較せよ。
