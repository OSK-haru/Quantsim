# P7. パルス計算の数値的作法

:::info[このページで学ぶこと]
- パルス計算が回路計算より数値的に厳しい4つの理由

- 作業量を数値計算の**前**に見積もって拒否する設計

:::

## P7.1 なぜパルスは厳しいのか

[第7章](../numerical-integration.md)で扱ったGate-awareの積分と比べて、パルス計算には4つの追加的な困難があります。

| 困難 | 内容 |
|---|---|
| **ハミルトニアンが時間依存** | 区間内で定数にできない。中点区分定数近似が必要 |
| **時間スケールの隔たり** | $\lvert\alpha\rvert \sim 1571$ rad/μs と $\gamma \sim 0.01\ \mu\mathrm{s}^{-1}$ が同居。5桁の差 |
| **次元** | 1台なら準位数そのもの(2 または 3)、$N$台なら $L^N$(最大81)。密度行列要素数は $L^{2N}$ |
| **ステップ数** | 1本のパルスに数千ステップ。それを求積点の数だけ繰り返す |

特に2番目が本質的です。[第7章](../numerical-integration.md) 7.4節で触れた**剛性**が、パルスモデルでは正面から効いてきます。速い方(非調和性、駆動)を分解できるステップ幅で、遅い方(緩和)まで積分しきる必要があります。

## P7.2 ステップ方針の3条件

Yuragi-Striderは、パルス区間に対して3つの条件を**同時に**課します。

$$
h\cdot G_H \le \varepsilon_H,
\qquad
h\cdot G_D \le \varepsilon_D,
\qquad
\frac{h}{\sigma} \le \frac{1}{N_{\text{samples}}}
$$

3つのうち最も厳しいものが採用されます。それぞれが守っているものは違います。

### 条件1: ハミルトニアンのスケール

$G_H$ は、その区間で現れるハミルトニアンの固有値の広がりです。含まれるのは

- 離調 $\Delta$
- 非調和性 $\alpha$(qutrit以上)
- 駆動振幅 $\Omega$
- 交換結合 $J$(ネットワークの各辺)

これが守っているのは**コヒーレントな位相の精度**です。$e^{-iEh}$ の位相 $Eh$ が $\varepsilon_H$ 以下でなければ、回転を追えません。

### 条件2: 散逸のスケール

$G_D$ は崩壊演算子から決まるスケールです。守っているのは**population の減衰の精度**で、[第7章](../numerical-integration.md) 7.4節の $h\cdot G \le C$ と同じ考え方です。

条件1と条件2を分けているのは、両者の大きさが桁で違うためです。ひとまとめの $G$ にすると、常にハミルトニアン側だけが効いて散逸側の条件が形骸化します。

### 条件3: 包絡線の形を分解する

$$
\frac{h}{\sigma} \le \frac{1}{N_{\text{samples}}}
$$

これは**波形をサンプリングする**条件です。前2つを満たしていても、$\sigma$ に対して $h$ が粗ければ、Gaussianの形そのものを再現できません。

矩形パルスには $\sigma$ がないので、この条件は Gaussian のときだけ効きます。

### 実装の定数

```text
Pulse Baseline A   (pulse_baseline_a_step_policy_v1)
    ε_H = 0.05,  ε_D = 0.05,  samples/σ = 20

Pulse Extension B  (qutrit_fixed_rk4_v1)
    ε_H = 0.02,  ε_D = 0.02,  samples/σ = 32

Coupled transmon network
    上に加えて h ≤ 0.02 / (4 max J_ij)
```

:::tip[なぜqutritのほうが厳しいのか]
Baseline A の $\varepsilon = 0.05$ に対し、Extension B は $0.02$。サンプル数も 20 → 32 と増えています。理由は2つあります。

**(1) 追跡すべき最速の時間スケールが増えた**
2準位では駆動 $\Omega$ が最速でした。3準位では非調和性 $\alpha$ が加わり、$\lvert\alpha\rvert \gg \Omega$ が普通です。$\lvert2\rangle$ の位相は $\alpha$ の速さで回るので、それを分解する必要があります。

**(2) 追いたい現象が微小**
[P3](./leakage-drag.md)で見たとおり、DRAGの効果は「漏れの一時的な膨らみを、終端で正確に打ち消す」という繊細な干渉です。数値誤差が漏れそのものと同程度になっては、DRAGの効果を測ったことになりません。

**測りたい量が小さいほど、必要な精度は上がります。** 定数の違いはモデルの目的の違いを反映しています。
:::

## P7.3 DRAGはステップ幅を厳しくする

[P3](./leakage-drag.md) P3.6 で触れた点を、数値の側から見ます。

DRAGを入れると、量子ビットが受け取る実際の駆動の大きさは

$$
\Omega_{\text{total}}(t) = \sqrt{\Omega_x(t)^2 + \big(\beta\,\dot\Omega_x(t)\big)^2}
$$

になります。ステップ方針は $G_H$ にこの**最大値**を使わなければなりません。$\Omega_x$ のピークだけを見ていると、クアドラチャ成分が大きい時刻でステップが粗すぎることになります。

実装は Gaussian について、この最大値を解析的に求めています。$r = \beta/\sigma$ とおくと、$r > 1$ のときに内部の停留点

$$
\left\lvert\frac{t-t_c}{\sigma}\right\rvert = \sqrt{1 - \frac{1}{r^2}}
$$

で最大になり、$r \le 1$ のときは端点かパルス中心が最大になります。

:::note[数値解法が物理の詳細を知っている]
「Gaussianの微分の最大値がどこか」という解析的な事実が、ステップ幅の決定に直接使われています。汎用のODEソルバなら誤差推定で自動的に対処するところを、**固定ステップ方針では事前に手で解いておく**必要があるわけです。

[第7章](../numerical-integration.md) 7.4節で見た「予測可能性」の代償が、こういう形で現れます。
:::

$\beta$ を大きくするほど $G_H$ が増え、必要ステップ数も増えます。**DRAGは計算を重くします。**

## P7.4 作業量を先に見積もる

パルスAPIの特徴的な設計が、**数値計算を始める前に作業量を判定して拒否する**ことです。

```text
Pulse Baseline A        : 200,000 ステップ
Pulse Extension B       :  25,000 ステップ
Coupled network         :  steps × ((L^N)^3 + 12,000) ≤ 1,200,000,000
                          samples × (L^N)^2 ≤ 250,000
                          CPTP は次元 ≤ 9 のみ / 500 区間
```

上限を超える要求は 422 で拒否されます。**計算を始めてタイムアウトさせるのではなく、始めません。**

| ステータス | 意味 |
|---|---|
| 422 | スキーマ・タイミング・モード・作業量の拒否 |
| 503 | 実行スロットが両方とも使用中(同時2ジョブまで) |
| 504 | 90秒の待機タイムアウトを超過 |

:::tip[これができるのは固定ステップだからです]
適応刻みのソルバでは、実行前にステップ数が分かりません。「解いてみないと分からない」ので、上限判定は事後的なタイムアウトにならざるを得ません。

固定ステップ方針は、$\sigma$、$\Omega$、$\alpha$、$\beta$、$J$、レートから**必要ステップ数を閉じた式で計算できます**。だから事前に拒否できる。

[第7章](../numerical-integration.md) 7.4節で挙げた「予測可能性」が、単なる設計思想ではなく具体的な機能として効いている例です。
:::

上限がモデルごとに大きく違うのは、1ステップあたりのコストが違うためです。2準位1台の $2\times2$ と、3準位2台の $9\times9$、3準位4台の $81\times81$ では、同じステップ数でも計算量が桁で違います。ネットワークは密行列積の $d^3$ に固定オーバーヘッド12,000を足した次元依存proxyで判定します。小さな次元では行列積そのものより1ステップの準備コストが効くため、この固定項がないと2台の要求だけが不釣り合いに長く走ってしまいます。さらにJSON応答へ含める密度行列要素数も別に制限します。

## P7.5 生の物理性診断

パルスモデルは、密度行列の整形([第7章](../numerical-integration.md) 7.6節)を掛ける**前**の値を別途保持します。

| 診断 | 何を見ているか | 危険な兆候 |
|---|---|---|
| `raw_trace_error` | $\lvert\operatorname{Tr}\rho - 1\rvert$ | $10^{-6}$ を超えたら疑う |
| `raw_hermiticity_error` | $\lVert\rho-\rho^\dagger\rVert$ | 同上 |
| `raw_minimum_eigenvalue` | $\rho$ の最小固有値 | **負なら非物理** |
| `cleanup_correction_norm` | 整形による補正の大きさ | 大きいほどステップが粗い |

**最も重要なのは `raw_minimum_eigenvalue` です。** [第7章](../numerical-integration.md) 7.6節で見たとおり、Hermite化とトレース正規化は半正定値性を**回復しません**。負の固有値は整形後も残ります。

:::warning[整形は誤差を隠しうる]
トレース正規化を掛けると `trace_error` は必ず 0 になります。整形後の値だけを見ていると、「うまく解けている」ように見えてしまいます。

生の値を保持しているのは、この錯覚を防ぐためです。**診断が「きれいすぎる」と感じたら、それが整形後の値でないかを確認してください。**

検証には、粗いステップ(0.006 μs、$\alpha = -215$ MHz)のqutrit DRAGパルスで、整形前の最小固有値が $-3.02\times10^{22}$ まで発散した記録があります。同じ条件で[明示的CPTP経路](../../physics-model/propagation/CPTP.md)は $9.9\times10^{-2}$ を保ちました。
:::

### RK4は有限ステップCPTPではない

[第7章](../numerical-integration.md) 7.5節の結論は、パルスモデルにもそのまま当てはまります。

$$
\text{RK4の1ステップ} = e^{h\mathcal{L}}\text{の4次多項式近似} \ \Longrightarrow\ \text{CP性の保証なし}
$$

Extension B の凍結された制限にも「**固定ステップRK4は厳密な有限ステップCPTP積分ではない**」が明記されています。これはバグではなく、手法の性質を正直に申告したものです。

明示的CPTP経路を使えばCP性は構成上保証されますが、[第8章](../quantum-channels.md) 8.8節のとおり、区間内で生成子が定数という前提の下でのみです。時間依存パルスには中点区分定数近似が入るので、**厳密な時間依存CPTP積分はどちらの経路でも得られません**。

ネットワークのCPTP区間上限が 500 なのは、$81\times81$ の行列指数を区間ごとに計算するコストのためです(次元9で1区間あたり約45 ms、500区間で約22秒)。同じ理由からCPTP経路はHilbert次元9以下に限られます。

区間幅そのものはRK4の精度上限に係数3を掛けた値です。GKSL指数は無条件安定なので、もっと粗い区間でも計算は破綻しません。しかし**安定性と精度は別物**で、区間が包絡線を分解できなければ「正しく積分された別のパルス」になってしまいます。誤差は区間幅の2乗で落ちるので、係数3は行列指数の本数と精度の折り合いとして選ばれています。非調和性の絶対値が大きいトランズモンや長い観測時間では区間数が増え、500の上限に当たることがあります。

## P7.6 収束次数を自分で測る

数値解が信頼できるかを確かめる最も直接的な方法は、**ステップ幅を変えて誤差の減り方を見る**ことです。

$$
E \approx C h^p
\quad\Longrightarrow\quad
p = \frac{\log(E_1/E_2)}{\log(h_1/h_2)}
$$

Yuragi-Striderのパルスモデルで測定された収束次数は **3.85〜4.05** です。理論値 4 と整合しています。

:::tip[次数が4より低く出たときの読み方]
実測 3.85 は 4 より低い値です。考えられる原因は次のとおりです。

| 原因 | 見分け方 |
|---|---|
| 中点区分定数近似の誤差が混入 | 区間分割を細かくすると次数が上がる |
| 参照解自体の誤差 | より細かい参照解に取り替えると変わる |
| 丸め誤差の床に近い | これ以上細かくすると次数が**下がる** |
| 包絡線の打ち切り不連続 | 端点の扱いを変えると変わる |

**次数が理論値ちょうどでないこと自体は異常ではありません。** 3.85 と 4.05 のあいだに収まっているのは、測定が意味のある領域で行われていることを示しています。

もし次数が 2 や 1 なら、それは実装のどこかが4次でないという明確な警告です。
:::

## P7.7 独立検証としてのQuTiP

3つのパルスモデルはすべて QuTiP 5.2.3 との独立比較を通過しています。

| モデル | ケース数 | 許容誤差 | 最大誤差 | 判定 |
|---|---|---|---|---|
| Baseline A | 6 | $5\times10^{-7}$ | $6.61\times10^{-8}$ | PASS |
| Extension B | 8 | $5\times10^{-7}$ | $5.03\times10^{-10}$ | PASS WITH RESTRICTIONS |
| Coupled network・RK4($L\in\{2,3\}$、$N=1$〜4) | 12(122チェックポイント) | $1\times10^{-7}$〜$5\times10^{-7}$ | $2.28\times10^{-9}$ | PASS |
| Coupled network・明示的CPTP(次元 ≤ 9) | 3(28チェックポイント) | $5\times10^{-5}$ | $2.07\times10^{-5}$ | PASS |

:::note[許容誤差は事前登録されている]
検証で重要なのは、**許容誤差を結果が出る前に決めておく**ことです。後から「この程度なら一致とみなす」と決めると、それは検証ではありません。

QuTiPは**検証専用**で、本番計算には使いません。独立な実装同士が一致することが、どちらも正しいことの証拠になります([第7章](../numerical-integration.md) 7.7節)。
:::

## P7.8 チェックリスト — 「実行できた」と「正しい」

パルス計算の結果を受け取ったとき、確認すべき順序です。

**第1段: 数値として成立しているか**

- `raw_minimum_eigenvalue` は負でないか
- `raw_trace_error` と `raw_hermiticity_error` は十分小さいか
- `cleanup_correction_norm` は無視できる大きさか

ここが通らなければ、以下の物理量には意味がありません。

**第2段: 収束しているか**

- ステップ幅を半分にしても結果が変わらないか
- ([P5](./quasi-static-noise.md))求積次数を上げても結果が変わらないか

**第3段: モデルの適用範囲内か**

- $\lvert2\rangle$ の population は大きすぎないか([P1](./transmon.md) 3準位切り詰めの前提)
- $\Omega$ は $\omega_{01}$ に比べて十分小さいか([第6章](../pulse-control.md) RWAの前提)
- レスポンスの `warnings` と `limitations` に何が書かれているか

**第4段: ようやく物理の議論**

- Fidelity、Purity、漏れ([第9章](../metrics.md))

:::warning[この順序を飛ばさないでください]
シミュレーターは、非物理的な結果でもエラーを出さずに数値を返すことがあります。**返ってきた数が物理量として意味を持つかは、利用者が確認する必要があります。**

Yuragi-Striderが診断・警告・制限を大量に返しているのは、この確認を可能にするためです。使わなければ意味がありません。
:::

## 演習

1. $\varepsilon_H = 0.02$、$\lvert\alpha\rvert = 1571$ rad/μs のとき、条件1が要求するステップ幅の上限を求めよ。

2. $\sigma = 0.002$ μs、$N_{\text{samples}} = 32$ のとき、条件3が要求する上限はいくらか。1番の答えと比べて、どちらが効いているか。

3. パルス長 $\tau_p = 6\sigma = 0.012$ μs を 2番の刻みで積分するとステップ数はいくつか。Extension B の上限 25,000 に対して余裕はあるか。

4. $\beta = \sigma$ のとき、$\Omega_{\text{total}}$ の最大値がピーク振幅の何倍になるか求めよ([P3](./leakage-drag.md) 演習4と同じ)。必要ステップ数は何倍になるか。

5. $J/2\pi = 10$ MHz で結合した3準位2台について $h \le 0.02/(4J)$ を計算し、iSWAP 時間 $\pi/(2J)$ を積分するのに必要なステップ数を求めよ。次元9での作業量上限に収まるか。

6. 誤差が $h$ と $h/2$ で $E_1 = 1.0\times10^{-6}$、$E_2 = 6.8\times10^{-8}$ だったとき、収束次数 $p$ を求めよ。

7. 🔬 同じPulse・環境に対し、**Pulseラボ**の「発展方式」を「固定ステップ RK4」と「明示的 CPTP 写像」にして実行せよ。「スナップショット数」はまず少なめ、その後多めにして、「最終純度」「目標状態との重なり」または「最終忠実度」「最終密度行列」を比較する。記録点を増やしても2解法の差が残る場合、表示指標だけがもっともらしく見えても数値誤差を疑うべき理由を説明せよ。

8. 🔬 **Pulse 回路スタジオ**でqutritのGaussian Pulseを選び、「Gaussian σ [μs]」を段階的に小さくして保存する。**Pulseラボ**へ戻るたびに「実行上限管理」の「UIによる保守的な見積り」を確認し、上限を超える設定で実行ボタンが無効になることを確かめよ。このUIでは不可能な要求をサーバーへ送る前に止めるため、前回の有効な結果が保持されることも確認せよ。

## パルス編を終えて

7章を通して、駆動された超伝導量子ビットの物理を、Josephson接合から数値計算の作法まで辿ってきました。

繰り返しになりますが、最も大切なことを最後に置きます。

:::warning[このモデルは較正済みハードウェアではありません]
- $E_J$、$E_C$ から $\alpha$ を導く回路モデルは持ちません($\alpha$ は入力です)
- $\gamma_{21} = 2\gamma_{10}$ は調和振動子由来の教育用近似です
- 位相緩和の $1:1:4$ はモデルが固定する予言であり、実測に合わせられません
- RWAのみで、Bloch–Siegertシフトも実験室系の搬送波も扱いません
- 準静的ノイズはガウス分布・離調のみで、$1/f$ スペクトルそのものではありません
- 完全なDRAGスキームのうち微分クアドラチャだけを実装しています
- ネットワークは非対称なコヒーレンス時間(直接レート入力時)、可変結合器、周波数チューニングを持ちません

**それでも、実装された範囲については何がどこまで検証されたかが完全に公開されています。**
:::
