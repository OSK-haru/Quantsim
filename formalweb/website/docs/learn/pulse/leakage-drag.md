# P3. 漏れとDRAG

:::info[このページで学ぶこと]
- 漏れ(leakage)の定義と、それが特別に厄介な理由
- 1次摂動論による漏れの見積もり — 「漏れ = 包絡線のFourier成分」
- 一時的な漏れと最終的な漏れの区別
- DRAGが漏れを打ち消す仕組みと、$\beta \approx 1/\lvert\alpha\rvert$ の由来
- Yuragi-Striderが実装しているDRAGと、実装していないDRAG
- $\beta$ を大きくしすぎると悪化すること

**前提**: [P1](./transmon.md)、[P2](./envelopes.md)
:::

## P3.1 漏れとは何か

計算に使うのは $\{|0\rangle, |1\rangle\}$ の2次元部分空間だけです。そこから外へ出た確率を**漏れ**といいます。

$$
L = \operatorname{Tr}\!\big(\rho\,\Pi_{\text{leak}}\big),
\qquad
\Pi_{\text{leak}} = |2\rangle\langle2|
$$

(3準位モデルの場合。一般には計算部分空間の直交補空間への射影です。)

漏れが他の誤差と質的に違うのは、**計算空間の外で起きる**ことです。

| 誤差の種類 | 通常の誤り訂正符号での扱い |
|---|---|
| ビット反転 $X$ | 検出・訂正できる |
| 位相反転 $Z$ | 検出・訂正できる |
| デコヒーレンス | 上の2つの組み合わせとして扱える |
| **漏れ** | **符号の想定外。検出できない** |

$|2\rangle$ にいる量子ビットは、$X$ でも $Z$ でもありません。符号のシンドローム測定は $\{|0\rangle,|1\rangle\}$ の中の話を前提にしているので、漏れた量子ビットは「意味不明な測定結果を出しつづける壊れた量子ビット」として振る舞い、しかも隣へ誤りを撒きます。

**実機で漏れが専用の対策(leakage reduction unit)を必要とするのは、この理由です。**

## P3.2 漏れを見積もる

[P2](./envelopes.md) で「漏れ $\sim |\tilde\Omega(|\alpha|)|^2$」と書きました。これを1次摂動論で導きます。

共鳴駆動($\Delta = 0$)の回転系では、準位のエネルギーは次のとおりでした([P1](./transmon.md))。

$$
E_0 = 0,\qquad E_1 = 0,\qquad E_2 = \alpha
$$

$|0\rangle$ と $|1\rangle$ が縮退しているので、この2つのあいだの遷移は共鳴です。一方 $|1\rangle\to|2\rangle$ は $\alpha$ だけ離調しています。

相互作用表示に移ると、$1\leftrightarrow2$ の結合は $e^{i\alpha t}$ の位相因子を持ちます。$|1\rangle$ から $|2\rangle$ への遷移振幅を1次で積分すると

$$
c_2 \ \approx\ -\,i\,\frac{\sqrt{2}}{2}\int_0^{\tau_p}\Omega(t)\,e^{i\alpha t}\,dt
\ =\ -\,i\,\frac{\sqrt{2}}{2}\,\tilde\Omega(-\alpha)
$$

$\sqrt2$ は[第6章](../pulse-control.md) 6.8節で見たはしご演算子の行列要素、そして残った積分は**包絡線のFourier変換そのもの**です。

$$
\boxed{\
L \ \approx\ \frac{1}{2}\big\lvert\tilde\Omega(\alpha)\big\rvert^2
\ }
$$

### Gaussianの場合

[P2](./envelopes.md) の結果 $\tilde\Omega(\omega) = A\sigma\sqrt{2\pi}\,e^{-\omega^2\sigma^2/2}$ と、回転角 $\theta = A\sigma\sqrt{2\pi}$ を使うと

$$
L \ \approx\ \frac{\theta^2}{2}\,e^{-\alpha^2\sigma^2}
$$

きれいな形になりました。読み取れることは3つです。

1. **回転角の2乗に比例** — 大きく回すほど漏れる
2. **$\alpha^2\sigma^2$ の指数関数で抑制** — パルスを長くすると急激に減る
3. **形状はFourier変換を通してのみ効く** — 面積が同じでも形が違えば漏れは違う

:::warning[この式は目安です]
1次摂動論は $|c_2| \ll 1$ を前提にしています。$\theta = \pi$ のような大きな回転では前提が破れ、実際の漏れは数値計算でしか出ません。

たとえば[検証B-4](../../physics-model/control_models/pulse-levelmodel.md)の $\beta = 0$、π パルスでの漏れ 0.2606 は、上式の摂動的な扱いが効く領域を明らかに超えています。

**この式の価値は数値ではなく、$\sigma$ や $\theta$ を変えたときにどちらへどう動くかが分かることです。** 実際の値はシミュレーターで測ってください。
:::

## P3.3 一時的な漏れと最終的な漏れ

パルスの途中で $|2\rangle$ の population を追うと、しばしば次のような形になります。

```text
P(|2⟩)
  │      ╭─╮
  │     ╱   ╲
  │    ╱     ╲___
  │___╱          ╲___
  └────────────────────→ t
      パルス中     終端
```

**パルス中に大きく膨らみ、終端で大きく戻ります。** これは離調 $\alpha$ による振動(周期 $2\pi/|\alpha|$)で、パルスが終われば駆動が消えるので、位相が揃えば戻ってくるからです。

したがって「漏れ」には2つの意味があります。

| 量 | 意味 |
|---|---|
| パルス中の最大 $P(\lvert2\rangle)$ | 過渡的。3準位切り詰めの妥当性を測る目安 |
| **パルス終端の $P(\lvert2\rangle)$** | 実際にゲート誤差として残る量 |

検証B-4が「パルス終端の漏れ」を報告しているのはこのためです。DRAGが狙うのも終端の漏れです。

:::tip[過渡的な漏れも無視できない]
終端で戻るとはいえ、パルス中に $|2\rangle$ を大きく占有していれば、その間に $|2\rangle$ 特有の散逸([P4](./qutrit-dissipation.md))が働きます。$\gamma_{21}$ は $\gamma_{10}$ より大きいので、$|2\rangle$ に長居するのは損です。

「終端で戻るからよい」とは言えません。
:::

## P3.4 DRAGの原理

**DRAG**(Derivative Removal by Adiabatic Gate)の考え方は次のとおりです。

駆動が入っていると、系の瞬間的な固有状態(dressed state)は裸の $|0\rangle,|1\rangle,|2\rangle$ とは少しずれます。ずれの大きさは $\Omega/\alpha$ 程度です。もし $\Omega$ が**十分ゆっくり**変化すれば、系は断熱的に dressed state に追従し、パルスが終われば元に戻ります(漏れなし)。

漏れが生じるのは、$\Omega$ が**速く変化する**ときです。系が追いつけず、dressed state からずり落ちる。その「ずり落ち」の大きさは $\dot\Omega$ に比例します。

$$
\text{漏れの原因項} \ \propto\ \frac{\dot\Omega(t)}{\alpha}
$$

DRAGは、**この項をちょうど打ち消す成分を、直交するクアドラチャ(90°ずれた位相)にあらかじめ加えておく**手法です。1次で消すための条件が

$$
\boxed{\ \Omega_y(t) \ =\ -\,\frac{\dot\Omega_x(t)}{\alpha}\ }
$$

$\alpha < 0$ なので $-1/\alpha = 1/|\alpha| > 0$ です。実装のパラメータ $\beta$ はこの係数に対応します。

$$
\beta \ \approx\ \frac{1}{\lvert\alpha\rvert}
$$

### 数値で確認

$\alpha/2\pi = -250$ MHz のとき

$$
\lvert\alpha\rvert = 2\pi\times250\times10^{6}\ \mathrm{s^{-1}} = 1571\ \mathrm{rad/\mu s}
\quad\Longrightarrow\quad
\frac{1}{\lvert\alpha\rvert} = 6.4\times10^{-4}\ \mu\mathrm{s}
$$

検証B-4で使われている $\beta = 0.001$ μs は、この見積もりと同じオーダーです。1次の理論値がそのまま最適とは限らないので、実際には $\beta$ をスキャンして最良点を探すのが普通です。

### なぜ「微分」なのか、直感的に

包絡線の立ち上がりと立ち下がりで、$\dot\Omega$ は逆符号になります。

```text
Ω_x(t)        ╱‾‾╲          (Gaussian)
dΩ_x/dt      ╱      ╲       (奇関数: 前半 +、後半 −)
```

パルス前半で $|2\rangle$ に押し込まれた振幅を、後半で逆位相で引き戻す。微分成分はこの「押して引く」を自動的に実現します。

そして重要な副産物として、**微分の全積分はゼロです**。

$$
\int_0^{\tau_p}\frac{d\Omega_x}{dt}\,dt = \Omega_x(\tau_p) - \Omega_x(0) = 0
$$

(打ち切りGaussianは両端で同じ値をとるため。)したがって DRAG成分は**正味の回転角を1次では変えません**。$\beta$ を足しても目標回転角の指定がそのまま生きるのはこのためです。

:::note[ただし厳密には変わります]
[P2](./envelopes.md) P2.1 で見たとおり、位相が時間変化するとハミルトニアンの可換性が崩れ、面積定理は厳密でなくなります。DRAGを入れると回転角は2次のオーダーでずれます。

$\beta$ を大きくしていったときに忠実度が単調に上がらないのは、この効果と、次節の駆動振幅の増大が効いてくるためです。
:::

## P3.5 実装が持つもの・持たないもの

Yuragi-Striderの実装を正確に述べます。

```text
包絡線が Gaussian のときのみ有効
直交クアドラチャ = drag_beta_us × dΩ/dt   (解析的な微分)
矩形パルスに β ≠ 0 を指定すると例外
```

$\beta$ は `drag_beta_us`(単位 μs)として直接指定します。$\alpha$ から自動導出はされません。

:::warning[実装されていないDRAGの構成要素]
文献の完全なDRAGスキームには、微分クアドラチャのほかに次が含まれます。Yuragi-Striderは**これらを持っていません**。

| 要素 | 内容 | 実装状況 |
|---|---|---|
| 微分クアドラチャ | $\Omega_y \propto \dot\Omega_x$ | **あり** |
| 動的離調補正 | $\delta(t) \propto \Omega_x^2/\alpha$ で駆動中の周波数を動かす | なし(離調は定数) |
| 高次DRAG | $\Omega/\alpha$ の2次以上を消す拡張 | なし |
| $\lambda$ の較正 | はしご行列要素比の実測値による補正 | なし($\sqrt2$ 固定) |

したがって、$\beta$ を最適化しても漏れが厳密に 0 にはなりません。到達できるのは1次補正の範囲です。実装は「DRAGという名前の一つの効果」を教育目的で見せるものであり、実機の較正済みDRAGを再現するものではありません。
:::

### なぜGaussian限定か

矩形パルスの微分は端点でデルタ関数になります。数値的に扱えないだけでなく、無限の振幅を要求するので物理的にも意味を持ちません。

実装は、包絡線がGaussianでない場合に $\beta \ne 0$ を指定すると例外を返します。**黙って 0 に丸めるのではなく拒否する**という設計です。

## P3.6 $\beta$ を大きくしすぎるとどうなるか

DRAGを入れると、実際に量子ビットが受け取る駆動の大きさは

$$
\Omega_{\text{total}}(t) = \sqrt{\Omega_x(t)^2 + \big(\beta\,\dot\Omega_x(t)\big)^2}
$$

になります。$\beta$ が大きいほど、この最大値が増えます。

Gaussianでは $|\dot\Omega_x|$ の最大値は $t - t_c = \pm\sigma$ の点で

$$
\max\lvert\dot\Omega_x\rvert = \frac{A}{\sigma}e^{-1/2} \approx \frac{0.607\,A}{\sigma}
$$

なので、$\beta/\sigma$ が 1 を超えるあたりからクアドラチャ成分が主役になってしまいます。

3つの悪影響があります。

| $\beta$ を上げすぎると | 結果 |
|---|---|
| 総駆動振幅が増える | RWAの前提($\Omega \ll \omega_{01}$)に近づく |
| 1次補正の前提が崩れる | 2次以上の項が無視できなくなる |
| ステップ方針が厳しくなる | 生成子ノルムが増え、必要ステップ数が増える |

:::tip[最適な $\beta$ は「探すもの」]
理論値 $1/\lvert\alpha\rvert$ は出発点にすぎません。実機でもシミュレーターでも、$\beta$ をスキャンして漏れが最小になる点を探すのが標準的な手順です。

**この探索を自分でやってみることが、この章のいちばん良い演習です。**
:::

## P3.7 検証B-4が示していること

[Pulse-levelモデル](../../physics-model/control_models/pulse-levelmodel.md)に記録されている数値をあらためて読みます($\beta = 0.001\ \mu\mathrm{s}$、π パルス)。

| 指標 | $\beta = 0$ | $\beta = 0.001$ | 変化 |
|---|---|---|---|
| パルス終端の漏れ | 0.260634 | 0.022695 | 1/11.5 |
| 目標忠実度 | 0.647631 | 0.936293 | +0.289 |

読み取るべき点が2つあります。

**(1) 漏れの減少と忠実度の改善が対応している**
漏れが 0.26 から 0.023 へ減り、忠実度が 0.65 から 0.94 へ上がりました。差分を見ると、失われた忠実度のかなりの部分が漏れで説明できています。**この条件では漏れが主要な誤差源だった**ということです。

**(2) それでも完全ではない**
$\beta$ を入れても漏れは 0.023 残り、忠実度は 0.94 止まりです。P3.5 で見たとおり、実装が1次のDRAGしか持たないためです。

:::note[この条件は意図的に厳しい]
漏れ 0.26 という値は、実機の高忠実度ゲート($10^{-3}$ 以下)とは比べものになりません。検証B-4は**DRAGの効果が見えるように意図的に厳しい条件**(短いパルス)を選んでいます。

現実的な条件を選べば $\beta = 0$ でも漏れは小さく、DRAGの差も見えません。**教材としては、効果が見える条件を選ぶほうが正しい**という判断です。
:::

## 演習

1. $L \approx \frac{\theta^2}{2}e^{-\alpha^2\sigma^2}$ を使い、$\theta = \pi/2$、$\lvert\alpha\rvert = 1571$ rad/μs、$\sigma = 0.002$ μs での漏れを見積もれ。$\theta = \pi$ にすると何倍になるか。

2. 同じ式で、漏れを $10^{-4}$ 以下にするために必要な $\sigma$ の下限を $\theta = \pi$ について求めよ。パルス長 $\tau_p = 6\sigma$ はいくらか。

3. 打ち切りGaussianについて $\int_0^{\tau_p}\dot\Omega\,dt = 0$ を確かめよ。両端で $\Omega$ が 0 でないことに注意。

4. $\max\lvert\dot\Omega_x\rvert = (A/\sigma)e^{-1/2}$ を微分して示せ。$\beta = \sigma$ のとき、総駆動振幅の最大値はピーク振幅の何倍になるか。

5. $\beta \approx 1/\lvert\alpha\rvert$ と $\sigma$ の比 $\beta/\sigma$ を、$\lvert\alpha\rvert = 1571$ rad/μs、$\sigma = 0.002$ μs について計算せよ。P3.6 の危険域に入っているか。

6. 🔬 **Pulse 回路スタジオ**でGaussian・回転角 $\pi$ のX Pulseを選び、「DRAG β [μs]」を `0` から `0.003` まで数段階変える。各値で「ブロックへ保存」し、**Pulseラボ**のqutritモデルで実行して「最終リーケージ P2」を表またはグラフにせよ。最小になるβを、Pulseラボに表示される「非調和性 [MHz]」から求めた $1/\lvert\alpha\rvert$ と比較せよ。

7. 🔬 **Pulseラボ**の「非調和性 [MHz]」を `-250` と `-350` に設定し、それぞれについて設問6のβ探索を繰り返せ。ほかのPulse・環境設定は固定し、最小の「最終リーケージ P2」を与えるβがどちらへ動くか、$\beta\propto1/\lvert\alpha\rvert$ と照合せよ。

8. 🔬 βを`0`と設問6で得た最適値にして同じPulseを2回実行し、**Pulseラボ**の「占有確率と品質指標」で「P2 / リーケージ」の時間変化を比較せよ。サマリーの「最大リーケージ P2」と「最終リーケージ P2」も記録し、DRAGが途中の膨らみと終端の残留漏れのどちらへ強く効いているか説明せよ。
