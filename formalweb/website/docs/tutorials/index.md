# 画面別チュートリアル

Yuragi-Striderの各画面が「何をする場所か」「どこを操作すると何が変わるか」を、画面ごとに説明します。物理モデルそのものの説明は[物理モデル詳細](../physics-model/overview.md)を参照してください。ここでは**操作**を扱います。

## 2つのワークスペース

アプリはまず2つのモードに分かれています。

| ワークスペース | 扱う対象 | チュートリアル |
|---|---|---|
| Gate-aware | 量子ゲートで組んだ回路。ゲートに有限の所要時間を与え、その間のノイズを見る | [Gate-aware 編](./gate-aware/index.md) |
| Pulse-level | ゲートより下の層。マイクロ波パルスの波形そのものからトランズモンの応答を追う | [Pulse-level 編](./pulse-level/index.md) |

2つのモードは状態を共有しません。Gate-awareで実行した結果はPulse側には現れず、その逆も同じです。

## ホーム画面(モードの選択)

起動直後(`/`)に表示されるのがホーム画面です。この画面の役割はモードを選ぶことだけです。

- **通常モードを開始** — Gate-awareワークスペースの[シミュレーションワークスペース](./gate-aware/simulate.md)へ移動します。まずはこちらから始めてください。
- **PULSEモードを開始** — Pulseワークスペースの[Pulseラボ](./pulse-level/pulse-lab.md)へ移動します。

画面上部の `ENGINE / KERNEL / MODEL / SOLVER` は、いま動いている計算構成の表示です(既定は Gate-aware開放系モデル + Lindblad / RK4)。

## 共通のナビゲーション

すべての画面の最上部に、細い計器レールが常に表示されます。

| 表示 | 意味 |
|---|---|
| `YURAGI-STRIDER` | 製品名 |
| `SIM / GATE-AWARE` などの符号 | 現在いる画面の識別子 |
| `REV 2.6` | インターフェイスの版 |
| `SYS ONLINE` | 稼働表示 |

右端のハンバーガーボタンでページ一覧が開きます(`Esc` で閉じます)。

:::info[モードをまたぐ移動はホーム経由]
メニューに出るのは**いま自分がいるワークスペースの画面だけ**です。Gate-awareの画面からPulseの画面へ直接は飛べません。いったん「ホーム」に戻ってから、もう一方のモードを選び直してください。これはモードごとに状態が独立しているためです。
:::

メニューの最下部には設定メニューがあります。
