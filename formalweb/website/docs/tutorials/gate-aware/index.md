# Gate-aware ワークスペース

Gate-awareモードは、量子ゲートで回路を組み、**ゲートが有限時間かかる間に環境ノイズが作用する**という前提で状態の劣化を観察するためのワークスペースです。モデルの中身は[Gate-awareモデル](../../physics-model/control_models/gate-awaremodel.md)を参照してください。

## 5つの画面

| 画面 | パス | 役割 |
|---|---|---|
| [シミュレーションワークスペース](./simulate.md) | `/simulate` | パラメーターを決めて実行する。中心となる画面 |
| [回路スタジオ](./circuit-studio.md) | `/circuit-studio` | 回路そのものを編集する |
| [アルゴリズム一覧](./algorithm-library.md) | `/algorithm-library` | 代表的なアルゴリズムを読み込む |
| [状態エクスプローラー](./state-explorer.md) | `/state-explorer` | 実行結果を Bloch球・密度行列・タイムラインで読む |
| [ヘルプ / Q&A](./help.md) | `/help` | 指標の意味と、結果の読み方 |

## 標準的な流れ

```text
アルゴリズム一覧 ─┐
                  ├→ 回路スタジオ（回路を編集）
ホーム ───────────┘        │
                           ↓
                  シミュレーションワークスペース（パラメーター設定・実行）
                           │
                           ↓
                  状態エクスプローラー（結果を読む）
```

はじめて触る場合は、[アルゴリズム一覧](./algorithm-library.md)からGrover探索を読み込んで、そのまま実行するのが最短です。

## 4つの画面が共有しているもの

Gate-awareの各画面は**同じ1つの回路**を共有しています。回路スタジオで置いたゲートは、そのままシミュレーションワークスペースの実行対象になります。別々の回路を持っているわけではありません。

一方、**シミュレーション結果は実行した瞬間の回路に紐づきます**。実行後に回路を編集すると、状態エクスプローラーは「表示中の回路に対応する結果がありません」と表示し、古い結果を出しません。回路と結果がずれた図を見せないための仕様です。

## 用語の対応

画面上の表記と、ドキュメント側の用語は次のように対応します。

| 画面の表記 | ドキュメントでの呼称 |
|---|---|
| 忠実度 | 状態忠実度 $F$ |
| 純度 | $\mathrm{Tr}(\rho^2)$ |
| 有効操作時間 | 忠実度がしきい値を初めて下回る時刻 |
| ゲートの実行方法 | ゲートコンパイルモード |
| 時間発展の解法 | [RK4](../../physics-model/propagation/RK4.md) / [明示的CPTP](../../physics-model/propagation/CPTP.md) |
