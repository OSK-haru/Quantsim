# 回路スタジオ(`/circuit-studio`)

Gate-awareシミュレーションで実行する回路を編集する画面です。**この画面では計算は走りません**。編集した回路は[シミュレーションワークスペース](./simulate.md)がそのまま実行対象にします。

:::note[Pulseとは無関係]
ここで組んだ回路は、Pulse Labの単一パルスモデルには接続されていません。Pulseのシーケンスは[Pulse 回路スタジオ](../pulse-level/pulse-circuit-studio.md)側で別に編集します。
:::

画面上部には現在の回路の要約(量子ビット数・列数・ゲート数・2量子ビットゲート数)が常に表示されます。

## 画面の構成

```text
┌ ツールバー（ファイル / 表示倍率）─────────────┐
├ ゲートパレット │ 回路図 ─────────────────────┤
├ ツールバー（履歴 / 編集 / 列）────────────────┤
├ ゲートインスペクター（ゲート選択中のみ）──────┤
└ ステータス行 ─────────────────────────────────┘
```

## ゲートパレット

左側のパレットは6つのグループに分かれています。

| グループ | 内容 |
|---|---|
| 量子ビット | 論理量子ビット数を 2〜8 から選択 |
| 1量子ビット | H, X, Y, Z, S, T, RX, RY, RZ |
| 測定 | M(MEASURE) |
| 制御 | CNOT, CZ, CP, CCX, SWAP |
| レジスタ | QFT, ORACLE |
| 通信表示 | MESSAGE, RECEIVED |

各ゲートにカーソルを合わせると、そのゲートの説明カードが出ます。

条件を満たさないゲートは押せません。CCX は3量子ビット以上、QFT と ORACLE は2量子ビット以上が必要です。

:::warning[6量子ビット以上のコスト]
ノイズありのシミュレーションは密度行列を扱うため、計算量が $4^n$ で増えます。6量子ビット以上を選ぶとパレット内に注意書きが出ます。まず時間ステップ数を小さくして試してください。
:::

## ゲートの置き方

置き方は2通りあり、ゲートの種類で手順が変わります。

**1量子ビットゲート・測定**
パレットのボタンを押して選択し、回路図のマス目をクリックします。パレットから直接ドラッグして落としても置けます。

**制御ゲート(CNOT, CZ, CP, CCX, SWAP)**
ゲートを選択したあと、まず1つ目の量子ビットをクリックし、続けて接続先の量子ビットをクリックします。ドラッグして配置することもできます。配置の途中は、ステータス行に「次にどの量子ビットを選ぶか」が表示されます。

**レジスタゲート(QFT, ORACLE)**
またぐ量子ビット数が可変です。ゲートを選択し、**ビット0(最下位)から順に**量子ビットをクリックしてレジスタを作ります。選択済みの量子ビットをもう一度クリックすると確定します。ドラッグした場合は、落とした行から下がまとめて指定されます。

盤面の数字はビット重み $k$(その量子ビットが $2^k$ を担う)です。上から順にクリックすれば、Quirk や Qiskit と同じオペランド順になります。

## 置いたゲートを直す

回路図上のゲートをクリックすると選択状態になり、**ゲートインスペクター**が回路図の下に現れます。ここでしか変えられない項目があります。

| 項目 | 対象ゲート |
|---|---|
| 回転角 $\theta$ | RX, RY, RZ, CP |
| マークする状態 | ORACLE(`params.marked_index`) |
| レジスタの順序を反転 | QFT, ORACLE |

インスペクターを閉じたいときは、ゲートの選択を外します。

ゲートを消すには、選択して `Delete` か `Backspace` を押すか、回路の外へドラッグして放します。置き場所を変えるだけなら、回路図上でそのままドラッグします。

## ツールバー

**上段(回路の中身を変えない操作)**

| ボタン | 動作 |
|---|---|
| インポート | `.json` / `.qscope.json` の回路データを読み込む |
| エクスポート | 現在の回路を `回路データ.json` として書き出す |
| データを確認 | 回路のJSON表現をその場で表示する |
| 表示倍率 | 拡大・縮小・等倍・回路全体に合わせる |

**下段(回路そのものを書き換える操作)**

| グループ | ボタン |
|---|---|
| 履歴 | 元に戻す / やり直す |
| 編集 | 選択項目を削除 / クリア |
| 列 | − 列 / 現在の列数 / ＋ 列 |

「クリア」は回路を空にします。出発点になる回路が欲しいときは、[アルゴリズム一覧](./algorithm-library.md)からプリセットを読み込むのが早道です。

## キーボードショートカット

| キー | 動作 |
|---|---|
| `Delete` / `Backspace` | 選択中のゲートを削除 |
| `Esc` | 選択を解除する |
| `F` | 回路全体が収まる倍率に合わせる |
| `Home` / `End` | 回路の先頭 / 末尾へ移動 |

同じ一覧は、画面下部のステータス行にも常に表示されています。

## 列とは何か

回路図の縦1本ぶんが**列(column)**です。同じ列に置いたゲートは同一の時間区間で同時に作用し、その列の所要時間は含まれるゲートの所要時間の最大値になります。つまり、**遅いゲートを1つ混ぜると、その列全体が遅くなります**。回路を横に伸ばすほど総時間が伸び、その間ノイズが作用し続けます。

詳しくは[Gate-awareモデル](../../physics-model/control_models/gate-awaremodel.md)を参照してください。

## 次のステップ

回路が組めたら、ナビゲーションから[シミュレーションワークスペース](./simulate.md)へ移動して実行します。
