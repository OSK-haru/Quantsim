# Pulse 状態エクスプローラー(`/pulse-state-explorer`)

[Pulseラボ](./pulse-lab.md)で実行した軌跡について、**状態が時間とともにどう動き、どう崩れたか**を読む画面です。ここでは計算は走りません。直前の実行が返した軌跡を見る場所です。

Gate-awareの[状態エクスプローラー](../gate-aware/state-explorer.md)と同じ読み方——**時刻カーソルを1本だけ共有し、指標・確率・密度行列を同じ瞬間で並べる**——をPulse-levelへ移した画面です。

:::note[Pulse-level専用]
表示されるのはPulseラボの実行結果だけです。Gate-awareの回路スナップショットはGate-awareの状態エクスプローラーに表示され、ここには読み込まれません。
:::

:::info[Bloch球はありません]
Gate-awareの状態エクスプローラーにあるBloch球は、この画面には**意図的に置いていません**。Bloch球は2準位の縮約状態を描く図です。Pulse-levelの状態は qutrit(3準位)や結合トランズモン($3^N$次元)で、計算部分空間へ縮約して球に描くと、**この画面でいちばん重要なリーケージがちょうど見えなくなります**。同じ情報は「占有確率分布」の $\lvert 2\rangle$ 成分と、密度行列の非対角成分で読めます。
:::

## 結果が表示されないとき

| 表示 | 状況 | 対処 |
|---|---|---|
| 結果なし | まだ一度もPulseを実行していない | 「Pulseラボを開く」から実行する |
| 再実行が必要 | 実行後にPulseの設定・波形・レーンを編集した | 現在の設定でもう一度実行する |

後者では結果自体は表示されたまま、上部に警告帯が出ます。Gate-aware側が回路の署名で結果の古さを判定するのと同じ仕組みで、Pulseでは**実行フォーム(モデル・環境・数値設定)・レーン上のPulse・実行ハードウェア制約**の組が指紋になります。ひとつでも変えれば「変更前の条件の数値を見ている」と表示されます。

## 時刻カーソル

この画面の中心は、全パネルが共有する**1本の物理時刻**です。

- 「物理時間」パネルの再生・スライダー・◀ ▶ で動かす
- 「占有確率」パネルのサンプル送りでも動く
- 動かすと、指標・確率遷移・密度行列の表示時刻が同時に揃う

初期位置は**Pulse終了時刻**です。Gate-awareが「回路の後」のスナップショットを初期表示にするのと同じ理由で、駆動を切った直後の状態がまず知りたい状態だからです。

## 表示項目の選び方

画面上部の「表示項目」メニューで、パネルの表示・非表示を切り替えます。「すべて表示」「すべて非表示」もここにあります。各パネルの見出しをクリックしても個別に開閉できます。

**初期状態では「指標タイムライン」と「確率比較」だけが開いています。**

## 各パネル

### 物理時間

パルス列を実時間の軸に並べ、再生しながら状態の変化を追うパネルです。帯は駆動区間・アイドル区間・仮想Zの瞬間に分かれ、シーケンス実行ではブロックのラベルが各区間に出ます。

Gate-awareの同名パネルが回路の列を実時間に並べるのに対し、こちらが並べるのは**波形の区間**です。仮想Zは時間を消費しないため、幅を持たない印として表示されます。

読み取り欄には、現在の区間・サンプル番号・Pulse終了時刻・その時刻の純度が出ます。

:::tip[動きを抑える設定のとき]
設定メニューでアニメーションを切っている場合、自動再生は無効になります。スライダーと ◀ ▶ で時刻を動かしてください。
:::

### 指標タイムライン

Gate-awareの指標タイムラインに対応するパネルです。時間の関数として次を重ねます。

| 系列 | 意味 |
|---|---|
| 純度 | $\mathrm{Tr}(\rho^2)$。環境と混ざるほど1から下がる |
| 目標状態との重なり / 閉じた系への忠実度 | qutrit単発では目標状態との重なり、2準位では散逸を切った閉じた系との忠実度 |
| リーケージ | 計算部分空間の外にある確率。qutritでは $P_2$、結合モデルでは計算基底以外の総和 |
| 区間状態変化 | 隣り合うサンプル間の密度行列の Hilbert–Schmidt 距離 |

Gate-awareでは「忠実度・純度がノイズの劣化を、区間状態変化がゲートによる状態の移動を表す」という読み方をしました。Pulseでも同じで、**区間状態変化が大きい区間ほど、波形が状態を回している区間**です。破線が立っていないのに純度が落ちていれば、それは駆動ではなく環境による劣化です。

縦の点線 `PULSE END` が駆動の終わりです。その右側は、駆動を切ったあとの環境だけによる発展です。

要約カードには、Pulse終了時と最終時刻の純度、参照値の最終値、最大リーケージ、最大区間状態変化、カーソル時刻の純度が並びます。

:::note[結合モデルに参照値はありません]
結合トランズモンペアと多トランズモン・ネットワークでは、参照する目標状態を単一の解析解として定義していないため、重なり・忠実度の系列は表示されません。純度とリーケージだけが指標になります。qutritのシーケンス実行でも、合成先を単一の目標状態として定義していないため同じく N/A です。
:::

### 占有数タイムライン

Pulseラボの結果にもある「占有確率と品質指標」のグラフを、時刻カーソル付きで表示します。準位ごと(または基底ごと)の占有確率を全部まとめて俯瞰したいときはこちらです。

### 確率比較

Gate-awareの「確率遷移：理想 vs ノイズあり」に対応するパネルです。基底状態をひとつ選び、その占有確率の時間変化を描きます。

**2準位モデルでは、散逸を切った閉じた系の軌道が重なります。** 2本の差がそのまま環境の寄与です。qutritと結合モデルではAPIが対応する閉じた系の軌道を返さないため、開いた系の1本だけを描きます。

下部には、カーソル時刻での開いた系の値・閉じた系の値・その差が出ます。

### 占有確率

カーソル時刻の占有確率分布です。Gate-awareの「出力確率」に対応しますが、**Pulse-levelでは測定を回路の一部として扱わないため、これは射影測定の結果ではなく密度行列の対角成分そのもの**です。

計算部分空間の外にある基底は色を変えて表示され、上部に「計算部分空間の合計」と「計算空間外の確率」が並びます。基底が13個以上のモデル(ネットワークなど)では、既定で確率の大きい上位12基底だけを表示し、ボタンで全基底に切り替えられます。

サンプル送りのスライダーは他のパネルと同じ時刻カーソルを動かします。

### 密度行列

カーソル時刻の完全な密度行列 $\rho$ です。対角が占有確率、非対角がコヒーレンスです。qutritは3×3、結合ペアは9×9、ネットワークは $3^N\times3^N$(最大81×81)になります。

大きい行列では「行列要素を検索」を使います。行・列に基底ラベル(例: `010`)または `#要素番号`(例: `#7`)を入力し、周辺幅±1〜±3を選ぶと、そのセルと周辺だけが表示されます。

:::tip[位相の変化は対角成分に出ません]
仮想Zのような位相操作は占有確率を動かしません。**変化は非対角成分にだけ現れます。** 対角だけを見て「何も起きていない」と判断しないでください。
:::

:::note[2準位モデルの密度行列は2点だけ]
2準位ベースラインの軌跡は占有確率のみを返し、密度行列はPulse終了時と最終時刻でしか得られません。このためこのパネルは最終時刻の密度行列を表示し、カーソルには追随しません。カーソルに合わせて動く密度行列が必要なら、qutrit以上のモデルを選んでください。同じ理由で、2準位では指標タイムラインの「区間状態変化」も表示されません。
:::

## 画面下部の要約

モデル名・トランズモン数・密度行列の次元・サンプル数・総観測時間が表示されます。シーケンス実行では操作数も出ます。サンプル数はPulseラボの「スナップショット数」で決まります。

## Gate-awareとの対応

| Gate-aware 状態エクスプローラー | Pulse 状態エクスプローラー |
|---|---|
| 物理時間(回路の列を実時間に並べる) | 物理時間(駆動・アイドル・仮想Zの区間を並べる) |
| 指標タイムライン(忠実度・純度・区間状態変化) | 指標タイムライン(純度・参照値・**リーケージ**・区間状態変化) |
| 確率比較(理想 vs ノイズあり) | 確率比較(閉じた系 vs 開いた系。2準位のみ2本) |
| 出力確率(測定の確率分布) | 占有確率(密度行列の対角成分) |
| Bloch球 | **なし**(縮約するとリーケージが隠れるため) |
| 密度行列(理想と並べて表示) | 密度行列(カーソル時刻の $\rho$) |
| Message → Receive | なし(Pulseに論理的な状態転送の概念がないため) |
