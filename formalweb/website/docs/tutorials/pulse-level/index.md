# Pulse-level ワークスペース

Pulse-levelモードは、ゲートより下の層を扱います。「Xゲートをかける」ではなく、**どんな形のマイクロ波をどれだけの時間当てるか**を指定し、トランズモンがどう応答するかを直接追うワークスペースです。モデルの中身は[Pulse-levelモデル](../../physics-model/control_models/pulse-levelmodel.md)を参照してください。

:::warning[実験的な機能です]
Pulse-levelは回転フレーム・RWA(回転波近似)に基づく実験的モデルであり、**校正済みのハードウェアモデルではありません**。デバイスプロファイルの制約値も実機の校正値ではなく、学習用の仮想デバイスです。
:::

## 3つの画面

| 画面 | パス | 役割 |
|---|---|---|
| [Pulseラボ](./pulse-lab.md) | `/pulse-lab` | 量子系モデル・外界環境・ハードウェア制約を決めて実行し、結果の要点を読む |
| [Pulse 回路スタジオ](./pulse-circuit-studio.md) | `/pulse-circuit-studio` | トランズモンごとのレーンにPulseを並べ、**波形そのもの**を編集する |
| [Pulse 状態エクスプローラー](./pulse-state-explorer.md) | `/pulse-state-explorer` | 実行済みの軌跡を、時刻カーソルを共有した指標・確率・密度行列で読み解く |

## 役割分担に注意

Gate-awareの「回路スタジオ / シミュレーションワークスペース」とは分担が違います。

```text
Pulse 回路スタジオ ── 各Pulseの波形（形・振幅・幅・位相・離調・DRAG）
                    └ シーケンスの並び

Pulseラボ ────────── 量子系モデル（準位数 2/3 × トランズモン数 1〜4）
                    ├ 外界環境（温度・T1・Tφ、または Lindblad率）
                    ├ 実行ハードウェア制約（AWG周期・分解能・上限）
                    ├ 実行
                    └ 結果の要点（波形・占有確率・最終密度行列）

Pulse 状態エクスプローラー ── 実行済み軌跡の読み解き
                    ├ 全パネル共通の時刻カーソル
                    ├ 指標タイムライン（純度・参照値・リーケージ・区間状態変化）
                    ├ 確率比較 / 占有確率分布
                    └ カーソル時刻の密度行列
```

**波形はPulse回路スタジオでしか編集できず、実行はPulseラボでしかできません。状態エクスプローラーは計算をしません。** トランズモン1台では選択レーンが実行対象です。2台以上では全レーンのスケジュールが渡され、同時駆動を含めて実行されます。

環境設定(温度・T1など)は**シーケンス内のすべてのブロックに共通**で適用されます。ブロックごとに温度を変えることはできません。

## 標準的な流れ

```text
ホーム → PULSEモードを開始
          ↓
        Pulseラボ（モデルと環境を確認）
          ↓
        Pulse 回路スタジオ（Pulseを並べる・波形を調整する）
          ↓
        Pulseラボ（実行して結果の要点を読む）
          ↓
        Pulse 状態エクスプローラー（軌跡を時刻ごとに読み解く）
```

初期状態では、q0のレーンに **X/2 → Y/2** の2つのPulseが最初から置かれています。まず何も変えずにPulseラボで実行し、占有確率が動くのを確認するのが最短です。

## Gate-awareとの関係

2つのモードは**状態を共有しません**。Pulseの結果はGate-awareの[状態エクスプローラー](../gate-aware/state-explorer.md)には現れず(Pulse専用の[Pulse 状態エクスプローラー](./pulse-state-explorer.md)で読みます)、Gate-awareの回路はPulse側の実行対象になりません。ナビゲーションメニューも分かれているため、モードを移るにはいったんホーム画面に戻ります。

状態エクスプローラーが2つあるのは、見るべき量が違うからです。Gate-aware側は理想回路とのズレとBloch球上の縮約状態を見る画面、Pulse側は**リーケージを含む多準位の占有と、駆動区間ごとの状態の動き**を見る画面です。詳しい対応表は[Pulse 状態エクスプローラー](./pulse-state-explorer.md#gate-awareとの対応)にあります。
