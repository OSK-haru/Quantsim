## Decision gate and bounded implementation update

The first bounded implementation now proceeds for the verified unitary path. The repository convention is recorded explicitly: `RY(theta)=exp(-i theta Y/2)`, therefore `exp(-iYt)` maps to `RY(2t)`. The powered Pauli is represented up to physically irrelevant global phase as `X^t ~= RX(pi*t)`, giving the ordered unitary `RX(pi*t) @ RY(2t)`. The implementation rejects non-finite parameters and wraps `animation_parameter_t` modulo one.

The following full-view conditions remain open and are intentionally not claimed complete:

1. Quirk source-level global-phase convention still needs an external source check; the physical density-matrix convention is now explicit and tested locally when numerical dependencies are available.
2. `MESSAGE` is now a first-class supported one-qubit operation, but stable operation IDs and a locked two-column expansion are not yet present.
3. Receive remains a non-mutating editor annotation, not an explicit backend checkpoint selector.
4. Core partial trace is now available as `core.gates.reduced_density_matrix`; transfer-metric and API extraction layers are still missing.
5. The existing `theta_rad` animation remains separate; Message uses `animation_parameter_t`.

The bounded implementation therefore includes the core Message unitary, explicit `animation_parameter_t`, and reduced-density-matrix primitive. The State Transfer View and parameter sweep should only be added after explicit Receive boundary metadata and reduced-state metric extraction are implemented.
