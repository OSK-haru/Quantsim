## 5. ライセンス条文の保持について

各ライブラリのライセンス条文および著作権表示は、以下の形で保持しています。

- Python パッケージ: 仮想環境内の各 `*.dist-info/` ディレクトリに原文を保持
- PyInstaller: `COPYING.txt`（Bootloader Exception を含む全文）
- npm パッケージ: `node_modules/` 内の各 `LICENSE` ファイル
- Rust クレート: Cargo レジストリキャッシュ内に保持
- 依存関係の完全な一覧とバージョンは `requirements-lock.txt`、`package-lock.json`、`Cargo.lock` に記録しており、監査時と同一の環境を再現可能です
